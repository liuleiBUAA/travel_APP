 去澳洲旅游、探亲访友（包括父母探亲）和短期商务访问，都是申请：： 访客签证（600类别）



 签证费用： 200澳元

 申请方式： 网上申请

 有效时间 & 停留时间： 1年多次，每次3个月

 审批时间： 一般1-4周

签证材料怎么准备等详看： 澳洲旅游签证攻略 



 网上申请步骤： 

1. 在线填写信息（半小时-1小时）

2. 上传签证材料

3. 支付签证费用



 备注： 

‣ 网上申请后，就是等待使馆审批，在线填写信息时所留邮箱，会收到出签信

‣ 每个人须递交各自的申请，比如父母带娃，就是3个申请（可以一个账户）

‣ 在线填写信息，不到20页，需半小时-1小时

‣ 在线填写信息，记得随时保存（可每页保存，按 Save 键），退出后随时登陆继续填写或修改；没保存就要重新填写

‣ 子女（满18岁）是澳洲公民或永久居民，父母来澳探亲，请看： 澳洲父母探亲签证攻略

 创建申请： 

登录 ImmiAccount 账户，一个 ImmiAccount 账户可创建1个或多个申请，一个申请对应一位申请人

如何创建：继续点击 New application 或 Copy 来创建，Copy 可以在之前申请上进行修改

适用情况：家人、朋友或同事等同行一起申请，可以注册一个 ImmiAccount

 关于建组 Group processing： 

适用情况：家庭成员、朋友或同事一起出行，可通过建组将申请材料关联，便于签证官综合考虑

建组步骤：

‣ 由第一个申请人创建组，勾选 Yes，再点击 Select group 创建，自定义 Group name（比如 Zhang’s Family）

‣ 系统自动生成一个 Group ID。其他成员可在同一个 ImmiAccount 户继续申请，勾选 Yes，将自动跳出已创建组

注意事项：

‣ 建组不代表会同时签出，可能由不同签证官审核，先后签出也很正常

‣ 建组虽然会关联材料，但是签证官主要还是基于申请人名下上传材料作出审核

比如夫妻建组申请，丈夫工作，妻子家庭主妇（无收入来源），妻子申请签证材料最好同时上传丈夫名下工作和资金材料

 ‣ 申请人打算多次入境澳大利亚吗？

单次就勾选 No，如果勾选 Yes，下面需要进一步回答。勾选 No 的情况下，申请人材料充分，现在基本都是给出多次签。

 ‣ 申请人计划在澳洲逗留多长时间？

旅游，一般探亲访友，商务目的，此处均勾选 Up to 3 months（不超过3个月），父母探亲在澳有身份子女满足条件可申请勾选 Up to 12 months。 注意普通旅游目的，要勾选Up to 3 months，超过3个月会要求体检！！

 上传签证材料






 



 以家庭为单位建组申请，还会列出以下清单： 

Group tour details（group name list，Itinerary）



 文件命名： 

 不能中文 。文件名字只能由数字0-9和大小写英文字母 A-Z，以及 – 和 _ 组成。 Description 可以保持和 Document Type 或者 File names 一致，也可以另取。



 文件上传要求： 

选取文件以后，点击 Attach 上传，上传成功以后，会显示 Date Received

 ‣ 单个文件大小不超过 5MB ，文件格式：bmp, dcm, doc, docx, dot, gif, jpg, pdf, png, ppt, pptx, rtf, txt, xls, xlsx。

 ‣ 要求扫描原始文件，不接受压缩文件和加密 pdf 文件。

 ‣ 要求高质量的， 方向正确的彩色扫描件 （和原始文件一致，原始文件若是黑白，则扫描成黑白）。如果提交低质量的扫描文件，可能会导致申请评审的延误或拒签。

 ‣ 多页材料的文件建议扫描成1个 pdf 文件，比如户口本按页码顺序扫描成1个不大于5M的 pdf 文件。其他但凡多于1页的文件同理。（可以下载手机扫描app进行扫描）。



 文件保留时长： 

Attach 以后，上传的文件将保留30天，如果没有提交，超过30天将被删除。



 用什么扫描： 

打印机/扫描 App/苹果手机备忘录（有相机扫描功能）

直接拍照也可（保证清晰度）

 支付签证费用






 



 支付方式： 借记/信用卡，贝宝或银联卡，以及只限于澳洲银行账户的BPAY。

‣ 国内用户，一般用信用卡或银联卡即可，会有2-4澳元的手续费。

‣ 可以多个申请合并付款。



 递交申请： 

点击右下角 Submit 成功支付以后，回到账户，申请账户状态会由 Ready to submit，变成 Submitted，展开申请，会给出官方预计审核时间长度，时间不等。



 等待审核： 

在线申请以后，就是等待了：等待审核和收到结果。



 查询进度： 

可通过账户查询进度，点击 View application status 查询签证处理进度；同时邮箱会收到邮件，准签信（or 拒签信）

祝大家伙不要等得太煎熬，都收到准签信^_^



 缴费后补充材料： 

提交签证（并支付）后，如发现漏交了材料，或者收到通知需要补充材料的情况下

1. 官网登陆账号： https://online.immi.gov.au/lusc/login 

2. 点击查看详情 View Details

3. 点击查看提交的材料 View attachments

4. 点击添加材料 Additional documents，添加补交材料，提交即可





 

 常见 Q & A


 Q：一个账户可以多人申请吗？ 

可以。家人/朋友/同事等都可以。



 Q：家庭前往，建立一个申请可以吗？ 

不可以，前往的每一个人，须递交各自的申请。



 Q：收到要采集指纹的邮件？ 

目前旅游目的，只有十年签需要采集指纹。如果收到邮件要采集指纹，检查一下 P2 目前所在地 Current location

生活和工作在中国大陆，Current location：China；Legal status：Citizen



 Q：收到要体检的邮件？ 

停留三个月内不需要体检，超过三个月需要体检。

P9 勾选6个月/12个月，会要求体检，澳洲600普通旅游签证只会给3个月。如已提交申请， Enquiry Form 更正为3个月



 Q：建组，会一起签出吗？ 

不一定，建组也可能分配给不同的签证官审核，先后签出很正常。

家庭建组申请，小朋友一般在父母都签出来以后最后才签出。

然后建组，并不保证所有申请人有相同结果，会关联，但仍将根据每个申请人情况进行审核。

更多建组问题，请看 中国团组申请在线递交的常见问题 



 Q：怎么申请3年多次？ 

自己申请，无法选择有效期是1年还是3年，由签证官决定。有 “白本自己申请，签证官给3年多次” 的案例，是极少数。一般（绝大多数情况）都是给1年有效期。

补充：旅游/普通探亲访友，找有资质旅行社，可以签3年多次。



 Q：签证材料需要翻译吗？ 

不需要。



 Q：已填写P17签证历史的情况下，不出现 Evidence of the applicant's previous travel 项，怎么办？ 

猜测是系统 bug，过往签证和出入境记录可以考虑上传到护照 Travel Document 一栏。



 Q：如果写了说明信，上传到哪里？ 

可以考虑上传到 “计划在澳旅游活动材料” 一栏。



 Q：银联卡支付失败的原因？ 

银联卡支付失败原因，可能是：银行卡关闭境外交易功能，电话客服或APP开启此功能。

卡中不需要有外币，直接人民币账户即可。
