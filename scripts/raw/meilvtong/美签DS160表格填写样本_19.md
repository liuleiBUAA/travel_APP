## 正文
美国签证DS160表格填写样本

 最后更新 2025-11-1 




 
 写在前面


 填表时 ：

1. 看不懂的英文，可以让 AI 翻译 

2. 拿不准的地方，可以直接把问题复制到 小红书 找答案 



 填表的关键 ：

填写真实信息

理由1：面签时会被随机提问，只要信息真实，就几乎不可能答错

理由2：你可以了解下什么是 '开盒' ... 美使馆的能力应该和他们类似吧，所以不要填虚假信息



 最后 ：

3. 中国籍去美国旅游的拒签率，过去3年在25%-30%之间（官方数据）

反过来说，签过率其实挺高的，祝大家好运！





 

 填表前的准备


 



 DS-160表必须在线填写 ，网址是： https://ceac.state.gov/GenNIV/Default.aspx 



 特别注意： 

填表开始后，如果中途停止20分钟不操作，系统会自动删除你填写的数据

因此，建议先记住你的 Application ID（图中紫色框）：



 





然后填写每页后，都点击页面最下方的 Save 按钮：



 



点击后会有下方提示，大意是你刚才填写的内容，会被保存30天

你可以选择继续填表(Continue Application)，也可以选择去吃饭（Exit Application）

在填表结束，最终提交前，则建议点击 Save Application to File 保存为文件



 



当你吃过饭，想继续填写时，重新打开填表网址 https://ceac.state.gov/genniv/ 

选择国家，输入验证码后，点击 调出申请表（Retrieve An Application），然后输入你的 Application ID, 就可以继续填写了





 应提前多久填写DS160表？ 

使馆已明确说明提示 要尽可能早，至少在出行前3个月完成





 随行儿童是否也要填写DS160表？ 

每个出行人都需要填表





 家人分开填表，可以在一起面签吗？ 

家庭成员的表格是要分开填写的，会有不同的申请号

但填写结束后，在系统进行预约面签时，允许填入多个160表申请号，最终在同一窗口面谈





 以前填写过DS160表，但没有记住Application ID,  重新填写没问题吧？ 

完全没问题，之前表格自动作废





 填DS160表格前需要预定机票和酒店吗？ 

不需要











 

 填表开始


 

选择语言 > 选择计划去面签的城市 > 输入验证码 > 点击 Start An Application 开始填表
