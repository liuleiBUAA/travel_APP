 迪士尼乐园简介


加州迪士尼由门对门的两个乐园组成：



 迪士尼乐园 Disneyland Park ：

游客最多，最经典，和上海迪士尼乐园类似， 但有星球大战园区 

1955年建立， 世界上第一家迪士尼乐园

2001年建立，补充了一些主题，相对适合成年人和大孩子玩



 门票： 成人104-149美金， 官网 或 Klook （ 支持微信/支付宝 ）购票，价格相同

 迪士尼乐园的快速通道与常见问题


 Q. 什么是 Lightning Lane 快速通道 ？ 



 Lightning Lane 就是 ‘快速通道’ 

迪士尼所有项目的入口都分为 普通通道 和 快速通道，后者排队时间短，但需要花钱买 Pass 才能走！

有两种 Pass 可以选择，并且不是二选一的关系，钱多可以都买！



 Lightning Lane Single Pass (LLS) 


仅针对以下2个项目的 Pass：

 - 迪士尼乐园 Disneyland Park - 星战园区的 Star Wars: Rise of the Resistance

 - 迪士尼加州冒险乐园 - 汽车总动员 Radiator Springs Racers

价格：18-35美金，只能当天用 Disneyland APP 购买

规则：1个 LLS Pass 只能约1个项目，用完作废，且当天不能再次购买



 Lightning Lane Multi Pass (LLM) 


针对普通项目的的 Pass

价格：34美金起/天，可以在买门票时购买，也可以当天用 Disneyland APP 购买

规则：1次只能约1个项目（ 但当天可以约多次 ），当玩完1个项目 或 约了1个项目2小时后 才可以再约下一个项目，如此循环

备注：购买这个 Pass 后，可以免费下载玩项目时拍的照片，在园区内也可以找摄影师免费拍照， 更多信息见官网

 Q. 迪士尼的花车巡游与烟花表演？ 



花车巡游和烟火表演不是每天都有， 具体请看这里 



迪士尼乐园有花车巡游：路线是从 小小世界 到 公园入口， 具体请看这里 

迪士尼乐园也有烟花表演 

表演时间：夏季/节假日每天，淡季周五到周日，晚上 9pm 或 9.30pm，持续10-15分钟， 取决于具体日期 

观赏地点：Main Street, U.S.A.（ 睡美人城堡前的区域 ）

推荐视频： Wondrous Journeys Fireworks Return to Disneyland 

 

 

 



加州冒险乐园没有烟花，但有水幕灯光秀 World of Color

表演时间：晚上 9pm / 10.15pm，持续约23分钟， 取决于具体日期 

观赏地点：最好的位置在湖北面（ 小美人鱼项目前 ），但需要中午12点开始用 APP 抢免费的 Virtual Queue 或者付费购买 World of Color Dining Package 或者 World of Color Dessert Party 

推荐视频： Ultimate Guide to Disneyland’s World of Color Dessert Party 

 

 

 



 

 Q. 迪士尼是否允许带食物？特色餐厅有哪些？ 



 ‣ 迪士尼允许自带无需加热的食品，零食和饮料（ 不能是玻璃容器或酒精饮品 ）

 ‣ 迪士尼乐园有很多地方可免费接饮用水（ 请自带水壶 ），去餐厅还可以免费要到杯子和冰块 

 ‣ 迪士尼每个园区都有40家以上的餐厅，可以用官方APP预约点餐

 ‣ 以下餐厅会有卡通角色出场 ，建议在官方APP上预订（ 最早可提前60天下手 ）

 Plaza Inn 35-60美金/人，常驻角色是米妮，可能还有维尼，跳跳虎，奇奇&蒂蒂， 参考视频见这里 

 Goofy's Kitchen 35-60美金/人，常驻角色是高飞，可能还有米妮，布鲁托，奇奇&蒂蒂， 参考视频见这里 

 Storytellers Cafe 35-60美金/人，常驻角色是米奇，可能还有米妮，布鲁托，奇奇&蒂蒂， 参考视频见这里 

 Disney Princess Breakfast Adventures 149美金/人，常驻公主是  Jasmine, Belle, Cinderella, Rapunzel, Ariel, Aurora, and Mulan， 参考视频见这里 





 Q. 带娃须知？ 



 ‣ 在入口处可以租婴儿推车，15美金/天，也可以自己带（ 但尺寸要在 31"x 52" / 79cm x 132cm 之内 ）

 ‣ 迪士尼的部分项目支持 Rider Switch 机制，解决家庭成员因身高限制，无法一起游玩的问题（ 项目列表见这里 ）： 全家一起排队进入项目，找工作人员，工作人员会把你们分为A/B两组，A组去玩，B组被扫描门票后，在指定位置照顾孩子，A组回来后负责看孩子，B组重新扫描门票，无需再次排队，就可以进入项目， 参考视频见这里
