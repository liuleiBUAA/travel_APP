 马蹄湾简介


马蹄湾的英文名称是 Horseshoe Bend 

是科罗拉多河在 Page 镇旁的一个270度转弯，观景点距离河面约305米，非常适合拍照



 开放时间 ：日出到日落， 日出/日落时间看这里 

 门票 ：10美金/车/次（ 不是1天 ），不接受国家公园年票

 玩多久 ：50分钟（ 因为停车场到观景点较远，往返需徒步1.5英里/2.4公里 ）

 最佳观赏时间 ：日出/日落时光影丰富，正午时景色最清晰

 官网 ： 请看这里

 马蹄湾的交通


马蹄湾位于美国的亚利桑那州，附近的著名景点有 羚羊谷 和 大峡谷 



 公交 ：可以在 拉斯维加斯 参加 羚羊谷+马蹄湾巴士一日游 

 自驾 ：

 ‣ 可以用 Horseshoe Bend Parking Lot 定位/导航

 ‣ 多数同学从 拉斯维加斯 出发，走小环线（ 1>2>3>6>7 ）到 羚羊谷和马蹄湾（ 地图中标号为6 ），具体请参考 美西国家公园环线攻略 

 ‣ 少数同学从 凤凰城 出发，走 凤凰城 - Sedona - 大峡谷 - 羚羊谷和马蹄湾 - 纪念碑谷 的环线，具体请参考 亚利桑那州旅游景点和攻略

建议住在 Page 小镇 ，距离 马蹄湾 8分钟车程，去 羚羊谷 也很方便

 马蹄湾怎么玩


 ‣ 停车（ 10美金 ）

 ‣ 从停车场 步行15分钟到观景点 - 全程无树荫，偶尔佐以风沙，请做好心理准备 ... 

 ‣ 观赏（ 观景台朝西，正午光线最佳，日出/日落时有明显的光影变化，都很美 ）

 马蹄湾和羚羊谷一日游示范行程


马蹄湾 与 羚羊谷 距离很近，可以与附近的小众景点，安排在同一天游玩

示范行程：

 ‣ 上午去 羚羊谷 （ 2小时，羚羊谷对光线要求高，所以安排在上午 ）

 ‣ 下午先去打卡附近的小景点，最热门的是观景点 2. Glen Canyon Dam Overlook （ 20分钟 ） 和 4. Wahweap Overlook （ 20分钟 ），如果对地图中的其他景点也感兴趣，可参考 这里的介绍 

 ‣ 最后去 马蹄湾（ 50分钟，景色最壮观，按照 ‘由俭入奢’ 的顺序，留到了最后 ）
