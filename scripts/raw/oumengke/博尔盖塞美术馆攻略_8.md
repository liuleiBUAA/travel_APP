博尔盖塞美术馆攻略 2026

 最后更新：2026-01-07 

 

 
 博尔盖塞美术馆 （意大利语Galleria Borghese；英语Borghese Gallery） 是一座位于罗马的美术馆，收藏有贝尼尼最具代表性的几座雕塑，除此之外还能看到卡拉瓦乔的代表作，以及拉斐尔、提香、鲁本斯等大师的作品。美术馆本身规模不大，位于博尔盖塞别墅，藏品多为文艺复兴巴洛克艺术品。美术馆所在建筑曾经是博尔盖塞家族的住所，最早的藏品来自于教皇保罗五世，后来这位教皇的外甥希皮欧内·博尔盖塞于1613-1620年间命人修建了此建筑，将家族藏品移至于此。希皮欧内·博尔盖塞本人是一位红衣主教，他非常热爱艺术，并且还是贝尼尼的赞助人。1903年之后成为意大利国立美术馆。



‣ 博尔盖塞美术馆的门票是强制预订的（包括免费票），并且比较热门，建议提前买，尤其是旺季



 门票预订： 官网预订 或 GetYourGuide预订 （官网售罄时可以捡漏，但价格更贵） 

 门票价格： €18 （其中门票本身€16，官网预定需要€2手续费） 

 开放时间： 周二至周日9am - 7pm

 闭馆： 每周一闭馆 ，1月1日、12月25日闭馆

 免费日： 每月第一个周日免费，但仍需要预约，需支付€2手续费 （提前10日放票） 

 参观时长： 2小时

 博尔盖塞美术馆门票注意事项 

‣ 美术馆采用分时段参观，每时段允许180人参观，时长为2小时

‣ 18-25岁EU citizens，票价€4（€2门票+€2手续费）

‣ 18岁以下免费，艺术 / 历史 / 建筑等学科的学生免费，需支付€2手续费 （ 免费列表 ） 

‣ 最后一个时段 （last slot 5.45pm-7pm） 票价为€13 （€11门票+€2手续费） 

‣ 有比较重要的临展时，门票可能会涨价







 博尔盖塞美术馆现场临时票 

‣ 如果没有提前买到博尔盖塞美术馆的门票，还可以去现场碰碰运气

‣ 馆方会在当天释放出少量现场票 （Last-Minute Tickets） ，但数量非常有限，无法保障是否能成功购买

‣ 现场票每人最多可购买2张；每个整点后20分钟开始购买

‣ 现场临时票的参观时长只有1小时30分钟；最后时段5.50pm开售，只能参观1小时

‣ 免费日 （每月第一个周日） 不提供现场临时票





 

 Roma Pass 罗马通票如何预约博尔盖塞美术馆？ 

‣ Roma Pass 是包含景点门票、交通日票的通票，48小时€38，72小时€62.9

‣ 博尔盖塞美术馆门票包含在Roma Pass中，预约是强制的，且建议尽早预约，防止票卖光了

‣ 预约时不需要卡号，也就是说没买Pass之前也可以把门票先预约了

‣ 预约成功后，入场时需同时出示Roma Pass



‣ 方法一： 点击官方链接 即可进行预约，最后需支付€2手续费

‣ 方法二：写邮件预约 romapass@tosc.it，无手续费

‣ 写邮件预约，会在48小时内收到确认信；周末会有延迟 （对比方法一，无法及时确认，但免费） 

‣ 更多信息： 罗马通票攻略 Roma Pass ； 购买Roma Pass 







 博尔盖塞美术馆语音导览： 

‣ 语音导览租金为€5，有中文选项可选

‣ 另外还有英文 / 意大利语讲解的Tour，感兴趣的同学可以在官网了解







 博尔盖塞美术馆存包： 

‣ 博尔盖塞美术馆要求所有的包必须寄存，无论大小；寄存免费

‣ 随身腰包或钱包，尺寸不超过21cm*15cm，可随身携带，无需寄存

‣ 有寄存需求的小伙伴，请提前前往美术馆，不要迟到







 如何前往 / 周边景点： 

 地铁： 乘坐LineA在Spagna站下车，然后步行前往，大约需要20分钟 （1.6km） 

 公交： 坐公交会更方便一些，美术馆旁边有公交车站-Pinciana/Museo Borghese，线路非常多
