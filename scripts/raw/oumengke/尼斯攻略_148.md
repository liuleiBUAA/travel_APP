尼斯旅游攻略——南法蔚蓝海岸之旅

 最后更新：2025-08-01 

 

 
 ‣ 尼斯 （Nice） 位于法国东南部，面朝地中海

‣ 所在的海湾叫做天使湾 （Baie des Anges） 

‣ 尼斯是法国第五大城市，并且拥有法国第三繁忙的机场

‣ 并且适合作为住宿根据地——游览蔚蓝海 （埃兹小镇、摩纳哥、芒通、戛纳等） 



 先对尼斯有个感性认识，推荐视频： 法国尼斯vlog ，UP主是黑板是谁 

 

 

 

 
 

 

 





 

 尼斯玩几天： 

 本城+周边： 至少三天，全程住在尼斯 （ 查询尼斯酒店 ） 

 本城： 尼斯不大，玩一天足够 （重点玩：海滩+城堡山） 

 周边必去： 埃兹小镇+摩纳哥+芒通一天；戛纳半天

周边小众：昂蒂布游览海岸（半天） / 格拉斯香水小镇（半天）/ 圣保罗德旺斯山城（半天）

薰衣草季推荐： 瓦伦索勒 + 圣十字湖 （6月中至8月中，报名参加 尼斯出发的一日游 ）

 如何前往尼斯： 

 飞机： 欧洲各大城市均可直飞尼斯，尼斯蓝色海岸机场 （Aéroport Nice Côte d'Azur，三字代码NCE） 

 火车： 尼斯火车站 （Gare de Nice Ville） 位于市中心 （ 火车票查询 ） 

 巴黎前往尼斯： 飞机1.5小时，火车5.5小时

 尼斯机场交通 / 公共交通 / 交通通票


‣ 尼斯机场位于市中心西南大约9km处，打车20分钟，大约€32

‣ 有两个航站楼，T1、T2之间可以免费乘坐电车

‣ 前往市中心：电车L2路，车程30分钟，T1、T2均可乘坐

‣ 如果住在梅德森大道 / 马塞纳广场附近，可乘坐至Jean Médecin站


 

 

 
 

 




 Q：尼斯机场到市中心的电车票多少钱？如何购买？ （ 查看官网信息来源 ）

‣ 如果直接在机场的电车售票机上购买，€10，包含返程，不是很划算



‣ 机场到市中心的电车，也可以用单程票€1.7、1日票€7、2日票€13

‣ 但是，上述票都无法在机场自动售票机上购买；可以通过下面两种途径购买

‣ 如果你的手机是安卓机，可以下载Lignes d'Azur Tickets APP进行购买

‣ 或乘坐电车至最近的Grand Arénas站，机场至此站免费，这一站机器可买€1.7单程票（以及1日2日票）

‣ 需额外支付卡费€2，这张交通卡后续可继续充值，用于尼斯及周边交通



‣ 价格€35的Sud Azur Explore Pass 3日通票也适用于机场电车，可以先看下 是否适合你 

‣ 如果适合，可直接在机场电车站的自助机器上购买





 Q：尼斯游览市中心，主要的交通工具是什么？ 

‣ 尼斯市中心步行为主，走不动了可以坐电车 / 公交

‣ 单程票€1.7，需先购买交通卡€2 （前面机场提到的） ，单程票74分钟内可换乘 （但不能往返） 

‣ 1日票€7 （有效期24小时） 、2日票€13 （有效期48小时） 

‣ 或者也可以购买神卡Sud Azur Explore Pass，也适用于尼斯市区交通



 

 Q：Sud Azur Explore Pass 尼斯3日通票是什么？ 

‣ Sud Azur Explore Pass是蔚蓝海岸 （Côte d'Azur） 、摩纳哥 （Monaco） 、滨海阿尔卑斯省 （Alpes-Maritimes） 推出的通票

‣ 3日通票€35，7日通票€50，以自然日期计算 （非24小时算法） ，需要先支付交通卡费€2

‣ 可以乘坐上述大区的所有公共交通，包括公交、电车、TER火车 （TGV的高速火车不能乘坐） 

‣ 如果计划在尼斯周边逛逛，比如前往摩纳哥、戛纳、芒通、埃兹小镇，买这种通票会比较划算

‣ 查看官方信息 ，此页面能查到购买地点、具体乘坐交通的种类





 Q：Sud Azur Explore Pass在哪里购买？ 

‣ 尼斯机场、市中心电车站自助售票机可购买

‣ 昂蒂布 （Antibes） 、戛纳、芒通、摩纳哥的购买地址， 请查看这里

 ❶ 英国人散步大道 & 尼斯海滩                                  返回地图 

‣ 英国人散步大道 （Promenade Des Anglais） 也被翻译作盎格鲁大道

‣ 是尼斯沿海的主干道，西起尼斯机场，东至城堡山丘脚下，长度大约7km

‣ 这条路是来尼斯旅行不能错过的，可以散步、骑自行车、坐在海边的椅子上看海

 ❸ 城堡山丘 - 天使湾最佳观景点                                  返回地图 

‣ 城堡山丘 （Colline du Château） 位于英国人散步大道的最东端

‣ 是俯瞰天使湾 （Baie des Anges） 和尼斯老城的绝佳观景点，另一侧还可以俯瞰尼斯港

‣ 11世纪至18世纪这座小山上伫立着一座城堡，1705年被路易十四下令拆毁，现在变成了城堡公园 （Parc du Château） 



 参观时长： 1-2小时

 如何上山： 两种选择，电梯or爬山，起点可以导航至Ascenseur du Château （靠近#ILoveNice墙） 

 电梯： 免费，开放时间10月至3月8.30am-6pm；4月至9月8.30am-8pm

 爬山： 大概15分钟



‣ 山顶西侧可以俯瞰天使湾，东侧可以俯瞰尼斯港，山头不大，西侧到东侧溜达15分钟就能抵达

 尼斯周边——埃兹 / 摩纳哥 / 芒通 / 戛纳


尼斯周边必去的目的地，可以分为两条线路：

 东线（一日游）：埃兹小镇 + 摩纳哥 + 芒通 （不想赶路，也可以用1.5天完成） 

 西线（半日游）：戛纳 


 

 

 
 

 


 周边小众：昂蒂布游览海岸（半天） / 格拉斯香水小镇（半天）/ 圣保罗德旺斯山城（半天）——篇幅原因，本文暂不详细介绍

薰衣草季推荐： 瓦伦索勒 + 圣十字湖 （6月中至8月中，报名参加 尼斯出发的一日游 ） 





 

 ----------- 东线：埃兹小镇 + 摩纳哥 + 芒通 ----------- 

‣ 早上：乘坐82路 / 602路公交，至埃兹小镇，游览2小时 （重点：植物园） 

‣ 中午：乘坐602路公交，至摩纳哥，吃午饭，游览3-4小时

‣ 下午：乘坐火车，至芒通，游览2-3小时；傍晚返回尼斯


 

 

 
 

 


 ‣ 82路（ 时刻表 ） / 602路（ 时刻表 ）公交班次不多，一定要计划好时间

‣ 从尼斯出发去埃兹，始发站是尼斯的Vauban车站（16 Av. des Diables Bleus）

‣ 不想行程太紧张，或冬天白天太短，可以将此行程割分为一天半游览 





如果不想自己操心交通，还可以考虑报名一日游：

 [尼斯出发] 埃兹小镇+摩纳哥（半日游 - 5小时） 

 [尼斯出发] 埃兹小镇+摩纳哥+昂蒂布+圣保罗德旺斯+戛纳（一日游 - 9小时） 









 

 埃兹小镇 Eze 

‣ 埃兹小镇位于尼斯和摩纳哥之间，因为建在陡峭的岩石上，所以也被称作为“鹰巢村”

‣ 埃兹小镇最有名的景点是热带植物园，可以俯瞰地中海

‣ 游览时间：热带植物园+小镇中心随便走走，2小时

‣ 如何前往：公交直达Eze Village站

‣ 82路公交：尼斯至埃兹20分钟 （不到摩纳哥） ，车票€1.7

‣ 602路公交：尼斯至埃兹30分钟，摩纳哥至埃兹25分钟，车票€2.1


 

 

 
 

 


 * Eze火车站位于山下，步行至小镇需1小时，或乘坐83路公交15分钟（班次极少）；故不推荐坐火车前往

* 镇中心公交车站：82路连接尼斯；602路连接尼斯尼斯 / 摩纳哥；班次少，提前看好离镇时刻表

* Fragonard是非常受欢迎的香水店，可以顺便逛逛 



 埃兹热带植物园（Le Jardin Exotique）： 

‣ 热带植物园修建在埃兹小镇的制高点，距离海面429米高，是蔚蓝海岸俯瞰地中海的最佳观景点

‣ 开放时间：11月-3月9am-4.30pm；4月至6月及10月9am-6.30pm；7月至9月9am-7.30pm

‣ 门票：成人€7，学生€4，12岁以下儿童免费


 

 

 
 

 


 图片来源：左 V2F ；右 Patrick Boucher 



‣ 埃兹小镇镇中心：镇中心很小，可以顺路逛逛


 

 

 
 

 


 图片来源：左 Thomas Konings ；右 Ekaterina Koliada

 摩纳哥 Monaco 

‣ 摩纳哥是世界上第二小的国家，摩纳哥面积仅2.02平方千米

‣ 然而这个国家的人均GDP却经常排名世界第一，街道上随处可见豪车，港湾里停满了游艇

‣ 摩纳哥的主要收入来源为旅游业和娱乐业，有著名的蒙特卡洛赌场、F1赛道



 602路公交： 埃兹至摩纳哥30分钟，车票€2.1

 600路公交： 从尼斯出发，车票€2.1，车程45分钟，15-20分钟一班， 时刻表 

 火车： 从尼斯出发，车票€5.9，车程25分钟， 火车票查询 

 详细攻略： 摩纳哥旅游攻略 

 玩多久： 半天

 注意： 欧洲的手机卡在摩纳哥需要额外付流量费用，可提前下载好Google map


 

 

 
 

 




 摩纳哥必去景点： 

大斜坡俯瞰港口 （最佳观景点） 、摩纳哥亲王宫 （摩纳哥城最重要的景点，可以不进入参观） 

蒙特卡洛赌场 （大堂免费参观，门口看豪车） 、F1赛道 （城市街道既赛道）

 芒通小镇 Menton 

‣ 芒通是蔚蓝海岸最东边的小镇，与意大利接壤，是一座有彩色小房子的小镇，特产是柠檬

‣ 火车：距离尼斯40分钟，距离摩纳哥10分钟， 火车票查询 

‣ 600路公交： 距离摩纳哥30分钟，€2.10，公交沿途海景；距离尼斯1.5小时，€2.10

‣ 芒通玩多久：2-3小时，景点主要集中在小镇东部，从火车站出发，大约步行20分钟，推荐从海边走，景色更好

 ----------- 西线：戛纳 ----------- 

 戛纳 Cannes 

‣ 戛纳是法国南部的一个沿海小城，每年5月会举办世界闻名的戛纳电影节

‣ 电影节之外，戛纳是一个拥有美丽沙滩、悠闲海岸的度假城市

‣ 火车：从尼斯出发车程35分钟，车票€9.4， 火车票查询 

‣ 玩多久：2-3小时，更多信息请参考 戛纳旅游攻略

 ----------- 薰衣草季 ----------- 

 瓦伦索勒 + 圣十字湖 

‣ 薰衣草季为每年6月中旬-8月中旬， 瓦伦索勒 的薰衣草田是普罗旺斯最有名的

‣ 圣十字湖 以蓝绿色的湖水著名，距离瓦伦索勒35km，可以一起游览

‣ 尼斯出发，无公共交通；非自驾的小伙伴，可以选择 尼斯出发的一日游（瓦伦索勒薰衣草 + 圣十字湖）
