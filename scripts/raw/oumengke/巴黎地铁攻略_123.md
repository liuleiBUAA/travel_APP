巴黎地铁攻略 2026

 最后更新：2026-03-23 

 

 
 ‣ 巴黎地铁 （Metro） 是巴黎旅行必不可少的交通工具，由 RATP公司 运营

‣ 巴黎还有RER轨道交通、公交、电车和火车，与地铁一起共享同一个系统的票券





 Q：巴黎地铁有分区吗？ 

‣ 整个巴黎分为巴黎大区 （Île-de-France region） 和小巴黎 （市中心） 

‣ 2025年巴黎交通做了很大的改动， 统一了巴黎大区的票价 ，票券系统简单了很多！

‣ 不用再被之前的zone1-5分区搞的晕头转向了

‣ 巴黎大区包括了： 巴黎迪士尼 、 凡尔赛宫 、 枫丹白露宫 、 戴高乐机场 、 奥利机场 


 

 

 
 

 


 ‣ 地铁Metro仅在小巴黎zone1-2运行，一共有14条线路 （Line 1-14） 

‣ RER是覆盖整个巴黎大区的轨道交通，一共有5条线路，用字母标注 （RER A-E） 



 

 Q：巴黎地铁如何买票？票价是多少？巴黎地铁APP推荐 

‣ 巴黎地铁买票，下载APP是最便捷的：IDF Mobilités 或者 Bonjour RATP 

‣ 两个APP都很方便，二选一即可，是两家不同公司开放的，都是官方APP

‣ IDF Mobilités：目前用的人多，遇到使用问题查信息比较容易

‣ Bonjour RATP：页面更清爽

‣ 在APP上买好票之后，需要开通手机的NFC功能，贴贴进闸机 / 乘车



 票价如下： 建议点击详细的票种，看看注意事项，很多需要避坑的Tips！

‣ Metro-Train-RER tickets ：地铁/RER单程票， €2.55 ，不能去机场，能去迪士尼、凡尔赛宫

‣ Bus-Tram tickets ：公交/电车单程票，€2.05

‣ 机场单程票 ： €14 ，适用于乘RER B往返戴高乐机场及地铁Line14等方式往返奥利机场

‣ Navigo 1-Day Pass ：日票， €12.3 ，不能去机场，能去迪士尼、凡尔赛宫

‣ Navigo Weekly Pass ：周票， €32.4 ，周一至周日，能RER B去戴高乐机场，能去迪士尼、凡尔赛宫

‣ Paris Visit Pass ：游客票，相当于机场票+日票，但不太划算


 

 

 
 

 




‣ 其他方法： Navago实体交通卡 （需支付额外卡费 / 不同票买不同卡，复杂） ；纸质票已被淘汰





 巴黎地铁票详解


 Metro-Train-RER tickets 地铁/RER单程票 

‣ 票价：成人€2.55

‣ 儿童：4-10岁半价，€1.30

‣ 有效期：2小时，可在地铁、RER、部分火车之间免费换乘

‣ 适用范围：巴黎大区 （Île-de-France region） ，机场除外

‣ 适用交通：地铁、RER、Suburban Train （近郊巴黎大区火车） 、蒙马特高地缆车

‣ 适用载体：手机 / 智能手表，Navigo Easy交通卡 （不适用Navigo Découverte交通卡） 

‣ 近郊景点：迪士尼、凡尔赛宫、枫丹白露都能去！

‣ 注意：如果手机里有One Way from/to Airports ticket，则无法购买Metro-Train-RER tickets （因系统无法判断先用哪张） 





 

 Bus-Tram tickets 公交/电车单程票 

‣ 票价：成人€2.05

‣ 儿童：4-10岁半价，€1.05

‣ 有效期：90分钟，可在公交、电车之间免费换乘 （但不能同路线往返、断程） 

‣ 适用范围：巴黎大区 （Île-de-France region） 

‣ 适用交通：公交Bus、有轨电车Tram

‣ 适用载体：手机 / 智能手表，Navigo Easy交通卡 （不适用Navigo Découverte交通卡） 





 

 Paris Region <> Airports ticket  机场单程票 

‣ 票价：€14，利用不同交通去不同机场，统一了票价

‣ 儿童：4-10岁半价，€7

‣ 适用下述述票种的载体：手机 / 智能手表，Navigo Easy交通卡 （不适用Navigo Découverte交通卡） 

‣ 往返戴高乐机场：RER B连接市中心

‣ 往返奥利机场：地铁Line14或RER B+Orlyval Line

‣ 有效期是2小时，可换乘；也就是说，从市中心先坐地铁或其他线路的RER，再换乘RER B或Line14，用一张票即可

‣ 如果你的手机/手表 或 Navigo Easy交通卡内有Metro-Train-RER单程票，则无法使用One Way from/to Airports ticket

‣ 因为刷卡系统无法判别出先刷你的哪张票





 

 Navigo 1-Day pass 日票 

‣ 日票票价： €12.3 

‣ 儿童：无优惠

‣ 有效期：按照日期计算 （非24小时制） 

‣ 适用范围：巴黎大区 （Île-de-France region） ， 不包括机场 

‣ 适用交通：地铁、RER、公交、电车、部分火车、蒙马特高地缆车

‣ 适用载体：手机 / 智能手表，Navigo Découverte交通卡、Navigo Easy交通卡

‣ 机场：不包含在内 （不能坐往返戴高乐机场的RER B、奥利机场的地铁Line14、Orlyval Line） 

‣ 近郊景点：迪士尼、凡尔赛宫、枫丹白露都能去！





 

 Weekly Navigo travel passes 周票 

‣ 周卡票价： €32.4 

‣ 儿童：无优惠

‣ 有效期： 周一至周日 （而非7天，也就是说，周中开始使用，仍然会在周日11.59pm到期） 

‣ 购买注意： 每周四午夜24点前可以购买当周的周票；周五只能购买下一周的周票 

‣ 谁买最划算： 在周四及之前抵达巴黎，并且需要停留超过3天，周票是最划算的选择 

‣ 适用范围：巴黎大区 （Île-de-France region） ， 包括往返戴高乐机场的RER B 

‣ 适用交通：地铁、RER、公交、电车、部分火车、蒙马特高地缆车

‣ 适用载体：手机 / 智能手表，Navigo Découverte交通卡 （不适用Navigo Easy交通卡） 

‣ 机场： 能坐 往返戴高乐机场的RER B，奥利机场的地铁Line14

‣ 近郊景点：迪士尼、凡尔赛宫、枫丹白露都能去！





 

 Paris Visit Pass 

‣ 1日€30.6，2日€45.4，3日€63.8，5日€78

‣ 儿童：4-9岁半价，4岁以下免费

‣ 功能上相当于：日票+机场票，价格没有优势 （对比日票，仅多了一个去机场的功能） 

‣ 适用范围：巴黎大区 （Île-de-France region） ，包括机场轨道类交通

‣ 适用交通： 地铁、RER、公交、电车、部分火车、蒙马特高地缆车、Orlyval Line

‣ 适用载体：手机 / 智能手表，Navigo Easy交通卡 （不适用Navigo Découverte交通卡） 

‣ 有效期：按照日期计算 （非24小时制） ，多日票需连续日使用







 巴黎地铁交通卡（不想用APP买票的替代方案，但有卡费！）


‣ 交通卡需要支付卡费 （不能退） ，相较免费的APP，交通卡在这方面没有优势



‣ 巴黎在2025年年底彻底取消了纸质票，如果你不习惯用手机支付，必须先买交通卡

‣ 巴黎游客可用的公交卡为：Navigo Easy （卡费€2） 、Navigo Découverte （卡费€5） 

‣ 下图是手机APP买票、Navigo Easy、Navigo Découverte分别可以储值的票券种类


 

 

 






‣ Navigo Easy： 卡费€2，是一张匿名卡，可以在自助售票机上购买

‣ 可以充值：Metro-Train-RER tickets、Bus-Tram tickets、日票、机场票、游客票 （Paris Visit Pass） 

‣ 不可以充值：周票 （Navigo Weekly pass） 

‣ 不能与同行者共享；有效期10年，下次再去巴黎可以继续用



‣ Navigo Découverte： 卡费€5，是一张适用于游客的实名卡

‣ 需要在人工柜台购买，提供证件照 （25*30mm） 、在卡上写名字

‣ 如果没有贴照片、签名，查票时会被罚款

‣ 可以充值 ：日票、 周票 （Navigo Weekly pass） 

‣ 不可以充值：所有的单程票 

‣ 丢卡不补：虽然是实名卡，但个人信息不会被记录在系统中，弄丢了卡是不能补办的

‣ €5卡费不能退，不过Navigo Découverte交通卡不会作废，下一次前往巴黎时，依然可以再次充值周卡


 

 

 
 

 






----------- 用Navigo Découverte交通卡购买周票注意事项 -----------

 有效期： 

‣ 周一至周日，而非7天 （也就是说无论在周几激活使用，都会在周日的午夜24点到期） 

‣ 每周四午夜24点前可以购买当周的周票；周五只能购买下一周的周票



 如何购买 / 注意事项： 

‣ 首先需要在人工柜台办理一张Navigo Découverte交通卡，此卡为实名卡

‣ 需提供1寸证件照（25*30mm）、卡背面签名，卡费€5 （不可退） 

‣ 再将Navigo Weekly Pass储值在这张交通卡中 （直接告诉工作人员即可） 

‣ 有些工作人员可能不会帮你贴照片，请务必自己贴好，并且写上自己的名字，否则查票会被罚款

‣ 虽然是实名卡，但因为个人信息不会被记录在系统中，所以丢失了之后无法补办





----------- 游客用不到的两种交通卡 -----------

‣ Navigo Liberte+、各种Navigo Travel Card

‣ 这两类卡适用于在巴黎长期居住的居民，但名字比较有迷惑性









 巴黎地铁常见问题


 Q：巴黎地铁和公交之间，可仅凭一张票免费换乘吗？ 

‣ 不可以，需要分别购买一张Metro-Train-RER ticket和一张Bus-Tram ticket





 Q：巴黎地铁可以直接刷银行卡/信用卡过闸机吗？ 

‣ 暂时不支持 （2026年3月更新） 





 Q：巴黎地铁对儿童有优惠吗？ 

‣ 4岁以下儿童免费

‣ 4-10岁儿童购买单程票半价

‣ 无日票 / 周票优惠





 Q：巴黎地铁对学生有优惠吗？ 

‣ 从外地前往巴黎旅游的学生，无优惠 （巴黎本土学生可以申请长期的优惠票券） 

‣ 需要额外注意的是，买票时不要误选reduce种类的票，这种票只适合4-10岁儿童及残障人士等群体



 

 Q：纸质实体票还有吗？ 

‣ 纸质票已于2025年年底被彻底取消
