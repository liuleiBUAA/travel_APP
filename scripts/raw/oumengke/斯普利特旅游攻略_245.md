 ‣ 斯普利特（Split）是克罗地亚的第二大城市，位于南部海岸，是一座港口城市

‣ 斯普利特也是这个区域内最古老的城市，公元305年戴克里先在此修建宫殿，距今已有1700年历史

‣ 斯普利特南部还有众多岛屿，以蓝色果冻海著名，跳岛游是一定要体验的项目

‣ 最少玩两天，一天游览市区，一天跳岛游（ 推荐预定 ）

 斯普利特老城必去景点 / 地图 / 行程推荐


‣ 斯普利特老城很小，景点之间步行距离非常短，一天时间可以完全悠闲地游览下来 （时间紧凑半天也可以） 

‣ 老城最重要的组成是戴克里先宫 （Diocletian's Palace） ，是“你中有我、我中有你”的关系

‣ 进入戴克里先宫是不需要门票的，需要购买门票参观的景点是教堂、钟楼、朱庇特神庙等小景点

‣ 一日行程推荐：可以从银门进入戴克里先宫，先游览列柱广场和教堂周边，再逛逛宫外几个广场，最后前往观景台

 戴克里先宫简介： 

‣ 戴克里先是历史上唯一一位因放弃权力而自愿退位的罗马皇帝，这座宫殿便是他为自己修建的退休场所

‣ 戴克里先宫修建于公元3世纪末，选址距离戴克里先的出生地Salona仅6公里

‣ 这位皇帝退休后的爱好之一是在此种卷心菜，其后有人曾要求其重登帝位，戴克里先拒绝并说出了那句有名的话：

‣ “当阁下看到敝人于索罗那亲手栽种的卷心菜时，便不会再提出这种要求。”

‣ 戴克里先去世后，这座宫殿仍然是罗马宫廷的财产，并在一些皇家成员被驱逐时为其提供庇护所



‣ 戴克里先宫是一个不规则的矩形，有四座城门，北长174.74米，南长181.65米，东长214.97米

‣ 宫殿南半部是公共、私人和宗教建筑，以及皇帝公寓；北半部是士兵、仆人居住的区域



‣ 公元5世纪，罗马帝国灭亡，戴克里先宫辉煌不再

‣ 公元7世纪，阿瓦尔人和斯拉夫人入侵，难民涌入宫殿城墙内部，找到庇护所

‣ 他们开始在宫城内修建房屋和街道，进行了新的、有组织的城市生活，造就了斯普利特老城的雏形

‣ 直至后来城市的建筑蔓延至宫墙之外，老城和戴克里先宫的界限便无法分清了

‣ 1979年，斯普利特老城被列为世界文化遗产；戴克里先宫占地面积约为老城的一半

 ❸ 斯普利特主教座堂 / 钟楼 / 地下墓穴 / 朱庇特神庙                      返回地图 

‣ 主教座堂 （Cathedral of Saint Domnius） 是斯普利特最地标的建筑

‣ 修建在罗马皇帝戴克里先的陵墓之上，该建筑本身建于公元305年

‣ 现在的教堂修建于公元7世纪之交，被认为是世界上最古老的天主教大教堂

‣ 教堂的钟楼 （Bell Tower） 历史可追溯至12世纪，高60米，登顶可俯瞰全城

‣ 教堂建筑群还包括地下墓穴 （Crypt） 、朱庇特神庙 （Baptistery） 、珍宝馆 （Treasury） ，可买套票参观

‣ 游览时长：每个建筑规模都很小，建议钟楼预留半小时，其他每个景点5-10分钟



门票价格：

‣ 教堂€5，钟楼€7，地下墓穴€3，朱庇特神庙€3，珍宝馆€5

‣ 绿色套票：教堂+钟楼+珍宝馆 €12

‣ 紫色套票：教堂+钟楼+珍宝馆+朱庇特神庙+地下墓穴 €15

‣ 钟楼是最值得参观的，还有一些不包含钟楼的套票，大家可以自行选择



开放时间：

‣ 周一至周六：8am-8pm，售票处1.15pm-2.15pm休息，7.30pm下班

‣ 周日：教堂/钟塔12pm-6pm；地下墓穴/朱庇特神庙/珍宝馆10am-6pm，售票处5.20pm下班

‣ 想体验海岛度假的小伙伴，可以选择 住在Brac岛 或者 住在Hvar岛

 扩展信息：长途轮渡 

‣ 从杜布罗夫尼克 （Dubrovnik） 往返斯普利特 （Split） 的公共交通，除了大巴之外，还可以选择轮渡，途径Hvar岛

‣ 杜布洛夫尼克与斯普利特之间的船程大约5.5小时，单程票价50欧元，每天一班船， 点击官网查询时刻表 / 购票 

‣ 如果是以轮渡作为交通，很推荐中途 在Hvar岛住1-2晚 

‣ Hvar岛往返Split岛大约需要1.5小时，船公司选择很多， 查看时刻表
