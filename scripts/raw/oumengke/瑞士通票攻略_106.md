 1 瑞士通票概况


瑞士旅行通票 Swiss Travel Pass 

 也称：瑞士火车通票/瑞士铁路通票 

以下简称：瑞士通票

 2026年瑞士通票和半价卡都有涨价 



 1.1 谁可以购买瑞士通票 

除瑞士和列支敦士登居民外

其他各国游客都可购买



 1.2 在哪里购买瑞士通票 

可在瑞士火车站售票处，也可提前在网上或手机购买

【中文页面，有使用手册，有中文客服】

成人25岁及以上，青年16-24岁，儿童6-15岁，6岁以下免费

 瑞士通票购买 >> ，成人CHF254起

 瑞士半价卡购买 >> ，CHF150





 1.3 瑞士通票的优点 

省时省力，一票搞定全程交通，不用一张张抢优惠票

没有乘车次数限制，特别是不怕坐错和迟到

免费乘坐全景列车，游客常去景点有大幅度优惠



 

 2 瑞士火车通票详情


瑞士通票分为【连续通票】和【活期通票】

 

 瑞士连续火车通票 

【名称】Swiss Travel Pass

【适合】在瑞士中短期旅游的游客

【规则】从使用日期开始 连续计日 ，没有使用的日期就作废了



连续使用3天，4天，6天，8天，15天；2等舱票价成人25岁及以上： CHF254，309，399，439，499 

青少年16-24.99岁：CHF179，218，282，311，356

16岁以下儿童免费，1家长最多可带4名儿童

 瑞士通票购买 >> 



 

 瑞士活期火车通票 

【名称】Swiss Travel Pass Flex

【适合】在瑞士中长期旅游的游客

【规则】可以在有效期内 间断使用 ，用一天算一天 



- 购买后首次使用时需激活，可根据指导网上激活

- 乘车时在车票上填写当日日期即可，当日可无限次乘坐

 [当日0点起效，可用到第二天凌晨5am；以此类推] 

- 乘车途中会有查票员，出示填写好日期的通票即可



全程使用3天，4天，6天，8天，15天；2等舱票价成人25岁及以上： CHF289，349，424，459，519

青少年16-24.99岁：CHF204，246，300，325，370

16岁以下儿童免费，1家长最多可带4名儿童

 瑞士通票购买 >> 



 

 2.3 瑞士通票的其他优惠 

 连续or活期通票都有以下优惠 

免费-乘登山火车上瑞吉山[卢塞恩]

免费-乘坐黄金快线[金色山口快线]列车，无需订位[因特拉肯—蒙特勒]

免费-乘坐冰河快线、巧克力火车、伯连纳快线，另付订位费

免费-乘坐湖上交通船/游船

半价-乘坐列车/缆车上First峰/雪朗峰[因特拉肯]

半价-前往Harder Kulm观景台 [因特拉肯]

半价-乘坐登山列车上马特洪峰-戈尔内拉特线[采尔马特]

半价-前往皮拉图斯山，铁力士山[卢塞恩]

优惠-乘列车上少女峰可优惠25%[因特拉肯]，但5-8月需定位

瑞士境内500家 博物馆 有免费/优惠

 全部路线和优惠 查看地图 >> 



 

 2.4 瑞士半价卡产品 

【名称】Swiss Half Fare Card

【适合】一个月内多次乘坐瑞士交通工具的游客

【规则】半价乘坐所有瑞士火车、公交车、轮渡和大部分登山火车

【价格】一个月内有效， 成人 CHF150 /张 

16岁以下儿童同父母一方同行可免费，1家长最多可带4名儿童

如果6-16岁儿童单独乘车，可以直接买半价票（无需半价卡）

 购买半价卡 >>
