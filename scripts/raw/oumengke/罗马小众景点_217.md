 观景台类——俯瞰罗马 

【概述】此类景点适合所有的旅行者，详细攻略可以阅读《 俯瞰罗马观景台汇总 》，地图参考 这里 


 

 

 
 

 


>> 苹丘观景台 ：免费，位于人民广场东侧，是市区最好抵达的免费观景台，适合看夕阳

>> 阿文丁山橘园 ：免费，位于整个市中心的南边，距离真理之口相对比较近，也适合看夕阳，还可以顺便游览“一眼看三国”（300米距离）

>> 马耳他骑士团修道院“一眼看三国” ：三国指的便是马耳他骑士团、意大利、梵蒂冈 - 透过马耳他骑士团修道院的大门锁孔，可以眺望远处的梵蒂冈圣彼得大教堂穹顶，可以和橘园一起游览

>> 维托里亚诺纪念堂观景台 ：门票€10，维托里亚诺纪念堂是位于威尼斯广场上的最显眼的建筑，楼顶观景台对外开放，距离斗兽场、万神殿都不远

>> 贾尼科洛山 ：相对其他观景台是一个比较大的区域，上图中是半山腰上的帕欧拉喷泉

>> Belvedere观景台 ：免费，位于Via Piccolomini这条小路的尽头，位置也很偏，属于小众中的小众景点





 广场喷泉类 

【概述】罗马有非常多的广场，广场上一般都坐落着雕塑、喷泉，有些广场是交通枢纽，有些广场可能因为一些小小的可爱的特点值得你顺路逛一逛，详细攻略可以阅读《 罗马广场与喷泉攻略大全 》，地图参考 这里 


 

 

 
 

 


>> 共和国广场 ：靠近火车站，广场旁有Repubblica地铁站

>> 威尼斯广场 ：如果打算从历史中心区域步行至古罗马区域，威尼斯广场是必经之地

>> 人民广场 ：广场北侧有Flaminio地铁站，苹丘观景台位于广场东侧

>> 巴贝里尼广场 ：广场很小，不过这里有贝尼尼创作的雕塑喷泉，并且有Barberini地铁站


 

 

 
 

 


>> 卡比托利欧广场 ：是卡比托利欧博物馆前方的广场，广场背靠古罗马广场

>> 弥涅耳瓦广场 ：非常小，靠近万神殿，广场上伫立着一座大象雕塑方尖碑

>> 鲜花广场 ：非常小，位于纳沃纳广场南部，生活气息浓厚，早上（除周日外）是露天集市，傍晚有很多露天餐厅

>> 银塔广场 ：是一个古罗马遗址广场，同时也是一座流浪猫庇护所

>> 四喷泉 ：位于一个十字路口的四座文艺复兴时期的喷泉

>> 帕欧拉喷泉 ：位于贾尼科洛山上，喷泉前的观景平台可以俯瞰罗马城





 博物馆 / 美术馆类 

【概述】适合对历史、艺术、文化感兴趣的同学参观，以下博物馆中 卡比托利欧博物馆、国家现代艺术美术馆、国立古代艺术美术馆 相对更重头一些，详细攻略可以阅读《 罗马博物馆与美术馆大全 》，地图参考 这里 


 

 

 
 

 


>> 卡比托利欧博物馆 ：主要收藏了大量古罗马雕塑，以及一些文艺复兴起的艺术作品


 

 

 
 

 


>> 国家现代艺术美术馆 ：收藏有克林姆特、莫奈、梵高、蒙德里安、波洛克、罗丹、杜尚等现代大师的作品，还是很厉害的，非常推荐给对现代艺术感兴趣的同学


 

 

 
 

 


>> 国立古代艺术美术馆 ：有两个分馆 - 巴贝里尼宫 和 科西尼宫，收藏有大量文艺复兴时期的画作，卡拉瓦乔的粉丝请不要错过



>> 罗马国家博物馆 ：有四个分馆 - 马西莫宫、戴克里先浴场、 阿尔滕普斯宫、巴尔比宫，主要是古罗马时期的文物收藏

>> 多利亚潘菲利美术馆 ：镇馆之宝是 委拉斯凯兹 的《英诺森十世肖像》

>> 卡洛·比洛蒂博物馆 ：收藏了意大利著名超现实画派大师乔治·德·基里科的17幅作品

>> 国立威尼斯宫博物馆 

>> 济慈-雪莱纪念馆 

>> 和平祭坛博物馆 

>> 罗马文明博物馆 

>> MAXXI 国立二十一世纪艺术博物馆 





 古罗马遗址类 

【概述】本部分大多数遗址是市区的标志性建筑，卡拉卡拉浴场可以进入参观，郊区的 阿庇亚古道公园 和引水渠公园适合想要避开人群、对古罗马历史感兴趣的同学；详细攻略可以阅读《 古罗马遗址汇总攻略 》，地图参考 这里 


 

 

 
 

 


>> 帝国广场大道 ：连接斗兽场和威尼斯广场，路两侧分布着很多遗址，最壮观的应该是图拉真市场




 

 

 
 

 


上图中的遗址均位于斗兽场和古罗马广场附近

>> 维纳斯和罗马神庙 ：是已知最大的古罗马神庙，位于古罗马广场的最东端

>> 马西莫竞技场 ：古罗马第一座也是最大一座竞技场，位于帕拉蒂尼山西南侧

>> 尼禄金宫 ：罗马皇帝尼禄的宫殿遗址

>> 马切罗剧场 ：外形很像斗兽场，但比斗兽场的建成却早了近100年，马切罗剧场有可能是最古老的剧院

>> 胜利者海克里斯神庙 ：位于真理之口对面，是一座可以追溯至公元前2世纪的神庙

>> 银塔广场 ：同时也是流浪猫庇护所




 

 

 
 

 


>> 卡拉卡拉浴场 ：是罗马第二大公共浴场，能同时容纳2000人洗澡，占地13公顷，门票€8

>> 塞斯提伍斯金字塔 ：建造于公元前12年

>> 奥古斯都陵墓 ：罗马帝国首位皇帝奥古斯都的陵墓




 

 

 
 

 


上图中的遗址均位于罗马近郊

>> 阿庇亚古道国家公园 ：阿庇亚古道是古罗马最古老也最重要的道路之一，整个公园占地3400公顷

>> 引水渠公园 ：面积大约为240公顷







 教堂类 

【概述】罗马一共有900多座教堂，如果你对文艺复兴时期的艺术比较感兴趣，那么请不要错过藏在各教堂内的大师作品，更多更全的教堂参观信息请阅读《 罗马教堂汇总攻略 》，地图参考 这里 


 

 

 
 

 


>> 胜利圣母教堂 ：贝尼尼的雕塑代表作之一《圣特蕾萨的沉迷》

>> 河畔阿西西的圣方济各教堂 ：贝尼尼的雕塑《受祝福的卢多维卡·阿尔贝特尼》




 

 

 
 

 


>> 圣王路易教堂 ：卡拉瓦乔《圣马太蒙召》《圣马太殉难》《圣马太和天使》

>> 人民圣母教堂 ：卡拉瓦乔的《圣彼得的磨难》《圣保罗皈依》，除此之外，这座教堂还有贝尼尼的雕塑和拉斐尔设计的基奇礼拜堂
