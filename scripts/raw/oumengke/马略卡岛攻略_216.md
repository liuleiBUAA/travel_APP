 马略卡岛基本信息


 西班牙语： Mallorca （也翻译作马约卡岛 or 马洛卡岛） 

 简介： 马略卡岛属于西班牙，坐落在地中海西侧，面积大约3,640平方公里 （对比：海南岛本岛面积为3.39万平方公里） 。马略卡岛多海滩，据统计全岛大约有262个海滩，总长度达50km，加上可爱温和的地中海气候，便宜的机票易抵达，这里成为了著名的度假海岛，尤其受到德国、英国的游客欢迎，甚至被称作为“德国后花园”。

 马略卡岛玩几天 / 怎么玩 / 住哪里 

- 建议至少住4晚，留出完整的3个白天，体验会比较好

- 自驾最方便，可以去公交无法抵达的漂亮海滩，以及景色最壮观的福门托尔角 （ 租车查询 ） 

- 公交也可以选择，只不过一些最好看的景点无法抵达

- 无论是自驾还是公交，都推荐住在马略卡的首府—— 帕尔马 （Palma de Mallorca） 



- 帕尔马的酒店又分为两种，住在市中心靠近长途车站，交通便利；

- 住在海滩，适合悠闲度假，但海滩距离市中心有点远 （市中心海边为海港，无海滩） ，去长途车站需换乘

- 自驾的小伙伴可以选择全程住海边，公共交通的小伙伴可以体验各住两天

 如何前往马略卡岛： 

- 马略卡岛的首府帕尔马 （Palma de Mallorca） 拥有机场

- 欧洲很多大城市均有直飞航班，机场代码为PMI （ 参考机场交通 ） 


 

 

 
 

 




- 马略卡岛属于巴利阿里群岛，此群岛另外三个主要的岛屿为：梅诺卡岛、伊维萨岛、福门特拉岛

- 但马略卡岛一般不会结合别的岛一起玩儿，原因：假期短、类型类似、轮渡耗时

- 如果想加一个目的地，不妨结合巴塞罗那一起玩儿，参考《 巴塞罗那旅游攻略 》

- 巴塞罗那至帕尔马的航班仅需45分钟，还可以选择轮渡

- 但轮渡耗时7-8小时又慢又贵 （如果你计划开自己的车上岛，轮渡是好选择；但 岛上租车 也很方便） 


 

 

 
 

 












 

 马略卡岛自驾行程推荐 

- 马略卡岛最著名的景点——福门托尔角、海滩Caló del Moro——公交都不是很方便，所以自驾是最优选择

- 选择公共交通的同学，可以参考下文 公交攻略 ，以及各景点的公共交通介绍

- 最推荐的方案是全程住在帕尔马，预留三个整天给三条路线，抵达或离开时的半天逛逛帕尔马市中心



 Day1： 早上抵达帕尔马，机场租车，入住帕尔马酒店，下午参观 帕尔马大教堂 

 Day2： 福门托尔角 为参观重点，下午结束后前往 阿尔库迪亚港的Muro海滩 

 Day3： 东南角小海滩Caló del Moro 为参观重点，之前可游览 德拉赫溶洞 ，之后可顺路打卡 南部海滩Cala Pi 

 Day4： 东北侧山区小镇Sóller / Deià / Valldemossa ，可以选择乘 木质小火车 （返程公交很方便） ，也可以自驾

 Day5： 可以再逛逛帕尔马老城区，或者专心泡酒店，或者离开

 位置： 帕尔马机场位于市中心以东12km处

 西班牙语： Aeropuerto de Palma de Mallorca

 机场代码： PMI

 机场租车： 查询价格 



 ---------- 机场大巴 ---------- 

- 前往帕尔马市中心：A1路公交，EMT公司运营，30分钟车程，单程5欧，上车现金买票 （ 时刻表查询 ） 



 A1路终点站是Passeig de Mallorca，途径长途车站 


 

 

 
 

 




- 前往其他目的地：TIB公司运营，可直达Alcúdia等小镇，但因为疫情原因暂停运行，详情参考 这里 



 ---------- 打车 ---------- 

- 工作日白天：周一至周五7am-9pm，起步价3欧，每公里0.93欧

- 工作日夜晚及周末节假日：起步价4欧，每公里1.1欧

- 前往帕尔马市中心大约是18-25欧，更多信息请参考 这里

 ---------- 长途公交 ---------- 

 票价： 按区域计算 ，单程票1.8欧-5.4欧 （刷卡价格） 

 如何买票： 用contactless的银行卡上车刷卡最划算 （信用卡和借记卡都可以） ，多人可刷一张卡，且有更多折扣，现金比刷卡更贵

 刷卡票价举例： 帕尔马至Sóller / Deià / Valldemossa单程为1.8欧，帕尔马至Alcúdia / Port de Pollença单程为5.4欧

 返回地图 



 帕尔马 Palma de Mallorca 

 简介： 帕尔马是西班牙马略卡岛的首府，最大的城市与港口，拥有机场，是来马略卡旅行的必经之地。帕尔马城市历史悠久，可追溯至古罗马时期。但帕尔马城市本身值得专门去的景点不多，必去的景点是帕尔马主教座堂，内部非常值得参观，加上在老城转转，建议给帕尔马市中心预留半天。



 帕尔马必去的景点是主教座堂，其他景点可玩可不玩儿，更多信息请参考《 帕尔马景点攻略 》 


 

 

 
 

 




 ---------- 帕尔马主教座堂 ---------- 

 简介： 帕尔马主教座堂 （Catedral de Mallorca，当地人耶也称为La Seu） 是最壮观的地标，也是帕尔马最值得进入参观的景点。主教座堂为加泰罗尼亚哥特式建筑，兴建在一座阿拉伯清真寺的遗址上，长121米，宽55米，通廊高44米，1601年修建完成，俯瞰着地中海。1901年高迪参加了教堂的修复工程，现在的主祭坛是由他完成设计的。

 参观信息： 门票8欧 （包含语音导览） ，开放时间10am-2.15pm （ 查询节假日开放时间 ）

 福门托尔角 Cap de Formentor 

 简介： 福门托尔角也被称为马略卡岛的“天涯海角”，马略卡人称海角为风的交汇点。福门托尔角是岛上最壮观、最值得去的景点，位于海岛的北部，高耸的悬崖山峰伫立在海中，此区域有观景台、海滩，海角尽头是一座白色的灯塔，山路蜿蜒曲折，非常有驾驶乐趣。



 公共交通： 

 - 公交334路连接Alcúdia、Port de Pollença、Mirador Es Colomer（天涯海角观景台），终点站是福门托尔海滩，无法抵达灯塔

- 334路为夏季专线，班次不多， 参考时刻表 / 路线图 

- 体力好的同学还可以选择在Port de Pollença租自行车前往Mirador Es Colomer，大约6.5km，需要注意坡度较大！

- Port de Pollença有多家自行车租车行，可以参考 这里 和 这里 



 自驾行程： 

 - 起点设置为距离海角最近的城市波连萨港（Port de Pollença），距离帕尔马50分钟车程，距离Alcúdia 15分钟车程

 东南角海滩：Caló del Moro / Cala S'Almonia / Cala Llombards 

 简介： Caló del Moro是马略卡岛最热门的网红海滩，水极清澈，被小丘包围，非常隐秘，从高处拍照特别好看；可以结合Cala S'Almonia一起玩，两个小海滩之间步行仅需5分钟；如果精力允许，还可以前往车程5分钟之外的Cala Llombards海滩。

 交通： 只有开车前往最方便；Caló del Moro附近无公交车站；最近的城市是Santanyí （大约6km，可以打车 / 可能需要提前预约） 



 停车场： 

 - 停车场1：Caló del Moro最近的停车场，但也需要步行15分钟才能抵达海滩（停车场1坐标84CG+77 Cala Llombards, 西班牙）

- 停车场2：位于Cala Llombards海滩尽头（停车场1坐标84FP+8X Cala Llombards, 西班牙）

 德拉赫溶洞 Drach Caves 

 简介： 马略卡岛多洞穴，Drach Caves是其中最有名的一个，位于岛东端，有地下河，可参观的部分大约1200米长，大概需要1小时，参观的结尾会有10分钟左右的小型古典音乐会，演奏家会乘着小船在地下河上演奏，是本溶洞最大的特色之一。

 门票： 建议提前 官网预订 ；成人（13岁及以上）15欧，儿童（3-12岁）8欧，2岁及以下免费

 开放时间： 溶洞采用分时段参观的模式，每日10.30am、12am、2pm、3.30pm各一场

 如何前往： 公交从帕尔马出发乘401路直达，1.5小时；自驾可免费停在景区停车场

 南部海滩：Cala Pi 

 简介： Cala Pi是小峡湾形成的海滩，海水青绿，位于马略卡岛的南部，很多小伙伴来此打卡是因为李敏镐曾来过这个海滩。

 交通： 自驾最方便；有公交，但班次很少，519d路，位于海滩旁，从帕尔马出发，需要在Llucmajor换乘

 停车场： 步行至海滩5分钟 （坐标9R8P+4R Torrent de Cala Pi, 西班牙）

 西部山区小镇与木质小火车 Sóller / Deià / Valldemossa 

 简介： 马略卡岛整个岛西北侧被特拉蒙塔纳山脉 （Serra de Tramuntana） 贯穿，山谷中坐落着很多美丽的古镇，适合挑选两三个花一天的时间游览，比较热门的小镇有索列尔 （Sóller） 、德亚 （Deià） 、巴尔德莫萨（Valldemossa）。鼎鼎大名的木质小火车路线也位于此山中，连接帕尔马与山谷小镇索列尔。



 - 如果计划体验小火车，那么推荐此日不开车，各小镇之间乘坐公交很方便

- 如果不打算体验小火车，自驾可以体验更多的地方，比如各小镇的海滩距离镇中心都比较远，但蛮适合开车去逛逛

- 自驾车程与公共交通的车程差不多，在此不重复标注了 


 

 

 
 

 








 ---------- A 索列尔 （Sóller） & 木质小火车 （Tren Sóller） ---------- 

简介：木质小火车拥有一百多年的历史，于1912年4月16日开通，最初是为了解决山区的运输问题，至今已成为马略卡岛著名的旅游项目。小火车连接首府帕尔马与山谷小镇索列尔，车程大约1小时。木质小火车还有一段电车延长线路，连接索列尔镇中心与索列尔港 （Port de Sóller） ，车程半小时。



时刻表： 参考官网 

票价：火车单程18欧，往返25欧；电车单程7欧；火车+电车往返联票32欧



 帕尔马乘车地点位于长途车站附近

 ---------- C 德亚 （Deià） & 德亚小海滩 （Cala Deià） ---------- 

简介：德亚相对于索列尔和巴尔德莫萨来说，是一个非常清净的小镇，镇中心不大，10分钟就能走完。相对于镇中心，更著名的是德亚小海滩，需要徒步40分钟抵达，沿途可以看到海景。
