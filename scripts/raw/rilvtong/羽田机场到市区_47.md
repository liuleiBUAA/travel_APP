 羽田机场到东京的交通


羽田机场距离东京市区约20公里

有3个航站楼，T3是国际航站楼，机场内有清晰的文字指示牌

如果要赶早/晚航班，也可以在机场里的酒店过夜： 皇家花园酒店 东京羽田 



 注意 ： 

想打车的同学，也可以直接用国内的滴滴APP叫车，不用另外下载，比出租车略便宜（ 也取决于是否在用车高峰期 ）



 羽田机场到新宿 ：

1. 铁路：京急机场线 + JR山手线，在 品川 换乘1次，总费用540日元，总时间约40分钟

2. 铁路：东京单轨电车 + JR山手线，在 浜松町 换乘1次，总费用730日元，总时间约40分钟

3. 巴士：也可以乘坐 直达巴士 ，票价1400日元，车程1小时，每小时2-3班

4. 出租车：8000-12000日元（ 晚10点以后会更贵些 ）

具体路线和时刻，可以用 Jorudan 查询



 羽田机场到浅草 ：

1. 铁路：京急机场线，直达，610日元，36分钟

2. 出租车：7500-11000日元（ 晚10点以后会更贵些 ）

具体路线和时刻，可以用 Jorudan 查询



 羽田机场到东京站 ：

1. 铁路：京急机场线 + JR山手线，在 品川 换乘1次，总费用510日元，总时间31分钟

2. 铁路：东京单轨电车 + JR山手线，在 浜松町 换乘1次，总费用690日元，总时间23分钟

3. 巴士：也可以乘坐 直达巴士 ，票价1200日元，车程1小时，每小时2-3班

4. 出租车：7000-10500日元（ 晚10点以后会更贵些 ）

具体路线和时刻，可以用 Jorudan 查询



 羽田机场到上野 ：

1. 铁路：京急机场线 + JR山手线，在 品川 换乘1次，总费用540日元，总时间40分钟

2. 铁路：东京单轨电车 + JR山手线，在 浜松町 换乘1次，总费用700日元，总时间30分钟

3. 出租车：7500-11000日元（ 晚10点以后会更贵些 ）

具体路线和时刻，可以用 Jorudan 查询



 羽田机场到成田机场 ：

1. 铁路：京急机场线，直达，成人1810日元，约需1.5小时

2. 巴士： 直达大巴 Airport limousine ，成人3600日元，约需1.5小时，可在线预订/现场售票机购票

3. 出租车：你不会这样做 ... ... 

具体路线和时刻，可以用 Jorudan 查询



 羽田机场到迪士尼 ：

1. 巴士： 直达大巴 Airport limousine ，成人1300日元，车程50分钟，可在线预订/现场售票机购票

2. 出租车：7500-11000日元（ 晚10点以后会更贵些 ）











 附录1：京急机场线 / 京急空港線


属于私铁， 可直达 品川，东银座，浅草 和 成田机场 

外观和内饰类似国内轻轨，最快14分钟可接入山手线（ 东京市区的JR环线 ）

早末班车：5.26am左右 - 0:20am左右

购票方式：自动售票机（ 使用方法 ）；支持 Suica 卡； 不支持 JR PASS

官网： 请看这里 



 

 
 
 




 1.红色为 京急线，绿色是 JR山手线

2.红色线路有两个方向，一条可直达 横滨 ，另一条可直达成田机场，不要坐错

 

补充说明：

- 到达品川站后，可以下车，换乘JR山手线，去新宿/涩谷/上野/东京站等

- 也可以继续坐车去 浅草（ 无需下车，京急机场线 自动改名称为 都营地铁-浅草线 ）

- 这列车最终目的地是 成田机场，官方大图 请看这里 

 

 


 
 
 


 







 附录2：东京单轨电车 / 東京モノレール / Tokyo Monorail


东京单轨电车是羽田机场前往东京市区的 交通工具之一 

每5分钟一班，最快 13分钟可接入山手线 （ 东京市区的JR环线 ）

早末班车：5am左右 - 23:55pm左右

购票方式：自动售票机（ 使用方法 ）；支持 Suica 卡；支持 JR PASS

官网： 请看这里 

其他：

周末/节假日还可买到 单轨电车+山手线内的优惠票 （ モノレール＆山手線内割引きっぷ ）

允许使用者从羽田机场出发， 在JR山手线任意一站下车 

成人540日元，小学生270日元，在自动售票机上购票



 

 
 
 




 单轨电车路线图 - 单轨电车（ 蓝色线条 ）仅能前往 滨松町 站

必须换乘 JR电车（ 绿色线条 ），才能前往 新宿/上野/东京/涩谷等地
