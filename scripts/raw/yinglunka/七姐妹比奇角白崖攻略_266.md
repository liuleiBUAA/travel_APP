 七姐妹比奇角白崖攻略 
 
 
 
 基本信息： 
 英文： 七姐妹 - Seven Sisters；比奇角 - Beachy Head 
 简介： 英国南岸有一种很独特的地质形态——白崖。七姐妹白崖便是其中最美的一段，由七座高地起伏的断崖组成；比奇角是最高点，最值得一看的是伫立在海中的红色小灯塔。这些景点距离英国南部滨海小城布莱顿很近，可以搭配一日游，所以备受欢迎。 
 
 左图：七姐妹白崖；右图：比奇角 
 
 
 
 
 左图：七姐妹是经典电影《赎罪》的取景地；右图：比奇角是周杰伦MV的取景地 
 
 
 
 
 
 
 
 行程如何安排 
- 首先需要先坐火车抵达 布莱顿（Brighton） 或者 伊斯特本（Eastbourne） （ 火车票查询 ） 
- 建议选择 布莱顿 ，比伊斯特本更热闹更好玩，可以顺便游览 （尽管伊斯特本距离景点更近） 
 
 
 
 
 
 
 七姐妹白崖和比奇角及周边可以分成两个独立的游览区域 
 如果你是自驾游览： 两个区域放在一天游览毫无问题，七姐妹白崖2小时 （最少） ，比奇角及周边2小时 （最少） 
 如果你是公交游览： 七姐妹白崖公交非常方便，可以与布莱顿各安排半天，从伦敦当日往返 （比奇角公交很少，冬季工作日不运营，建议舍弃） 
 
 
 
 
 详细交通请参考： 布莱顿如何前往七姐妹白崖 ； 自驾 / 公交如何游览比奇角 
 
 
 
 布莱顿酒店推荐： 
 前文说过，当日往返伦敦是可以实现的，但也非常推荐 在布莱顿住一晚 ，体验一下滨海小城的夕阳，在海边走走

 游览注意事项： 
- 本文介绍的景点，均为陡峭的悬崖，请务必远离崖边，安全第一 
- 悬崖处风比较大，紫外线也比较强烈，大家做好防风防晒措施 
- 主要游览方式是徒步，所以穿舒服的鞋很重要 
 
 
 
 
 
 七姐妹白崖攻略 
 从布莱顿出发去七姐妹分为两步： 
首先：乘公交 / 自驾至七姐妹游客中心 
然后：从游客中心徒步至七姐妹海边 
 
 
 
 
 
 
 从布莱顿至七姐妹游客中心的交通 
 自驾： 车程40分钟，大概25km，游客中心停车￡3两小时，￡4一天 
 公交： 12 / 12A / 12X路，车程1小时-1小时20分钟，票价单程￡4.4，往返￡6.9，在Seven Sisters, Park Centre站下车 
 
 - 查询12 / 12A / 12X路时刻表、路线图、票价表 
- 班次非常频繁，大概10分钟一班车；并且会运营到很晚，非常方便 
- 如果从伊斯特本出发，也是乘坐12 / 12A / 12X路，车程20分钟，单程￡3.3，往返￡5 
 
 如果在布莱顿火车站附近乘车，在Brighton Station Stop D乘车（下图左） 
如果在布莱顿市中心乘车，在Churchill Square商场附近的Dyke Rd Stop K乘车（下图右） 
 
 
 
 
 
 
 
 从游客中心至七姐妹白崖的徒步 
- 游客中心有卫生间和餐厅 
- 目的地可以分为三个：A观景点，B海滩，C七姐妹白崖 
- A和BC之间有一条小河，水不深但也不好通过，所以出发前你需要选择你是更想去A，还是更想去B和C 
 
 
 
 
 
 A观景点： 观赏七姐妹白崖的最佳地点，可以以小房子为背景，走上图小河以西粉色环线全程1.5分钟 （起点可以设定为The Cuckmere Inn） 
 B海滩 / C白崖： 不用拘泥于路线，只要沿着小河以东超海边走就行，纯走到海边需要30分钟； 
到海滩之后有路可以爬上白崖，往返游客中心全程预计至少1.5小时-2小时 （取决于爬上白崖想走多远，花多长时间休息和拍照）

 比奇角攻略 
- 比奇角附近景点还有Birling Gap （七姐妹尾端） ，Belle Toute灯塔，时间充裕可以一起游览 
- 自驾：最方便的方式，各停车场距离景点都很近 
- 公交：此路段也有公交，13X路，但班次很少，冬季只有周日运营，不是很方便 
- 打车：还可以选择从伊斯特本打车，至比奇角车程10分钟，返程请留好司机的电话让他来接 
 
 
 自驾游览比奇角 
 
 
 
 
 选择一： 可以在三个景点分别停车游览，必去的是比奇角，另外 灯塔望向比奇角的景色 是最好的，也推荐踩一脚 
 选择二： 停车在Belle Tout灯塔，徒步至比奇角，往返4.6km，加拍照休息大约需要2小时 
 选择三： 停车在Birling Gap，徒步至比奇角，往返6.8km，加拍照休息大约需要3小时 
 
 
 
 公交游览比奇角 
 
 
 
 
 查询13X路完整路线 / 时刻表 / 价格表 
 
 - 13X路冬天只有周日和节假日每天3班，夏季每天班次也非常少，需要认真计划 
- 布莱顿至比奇角乘13X：车程1小时15分钟，单程￡4.4，往返￡6.9 
- 七姐妹至比奇角乘13X：车程20分钟，单程￡2.7，往返￡4.5 
- 伊斯特本至比奇角乘13X：车程10分钟，单程￡2.8，往返￡4.8 
- 5-13岁儿童半价，除此之外还有覆盖整个布莱顿至伊斯特本的公交日票￡9可以选择 
 
 
 
 景点简介 
 下面按照从西至东的顺序来介绍 
 ------------------ Birling Gap ------------------ 
Birling Gap是七姐妹白崖的最东端，在这里可以从另一个方向欣赏七姐妹的景色，并且紧邻停车场，有餐厅和卫生间，设施很方便 
 
 
 
 
Birling Gap有木梯可以下到海滩 
 
 
 
 
 
 ------------------ Belle Toute灯塔 ------------------ 
灯塔内部改建成了B B，感兴趣的同学可以去他们的 官网 了解预定 
 
 
 
 
从Belle Toute停车场看向灯塔方向 
 
 
 
 
 
 ------------------ 比奇角 Beachy Head ------------------ 
 从Belle Toute停车场看向比奇角方向 
 
 
 
 
比奇角是英国最高的海岸悬崖，高165米，伫立在海中的灯塔高43米，距离悬崖165米
