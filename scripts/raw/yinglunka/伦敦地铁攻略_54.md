 伦敦地铁攻略：牡蛎卡 Oyster Card / Contactless 
 
 
 
 （本文的讨论是针对前往伦敦的短途旅行者，要在伦敦上学和工作的小伙伴们，本文不适用于你们，详细信息可参考官网） 
 
 伦敦交通简介： 
&#8227; 对于短期在伦敦旅行的小伙伴，地铁（Tube）是最重要的交通工具 
&#8227; 伦敦地铁分为9个区，绝大部分景点集中在zone1内 
&#8227; 地铁与这些交通公用同一套票券系统：公交、DLR （轨道交通） 、Overground （轨道交通） 及市区火车 
 
&#8227; 伦敦地铁支付方式：Oyster Card牡蛎卡，或者带有Contactless功能的银行卡 / 电子设备 
&#8227; Zone1地铁票价：单程￡2.9，Off-peak时段￡2.8，当日封顶￡8.9，7日票￡44.7 
 *这里指Oyster或Contactless票价；如果用现金购买，单程￡7（zone1-6范围内，均为此价格），巨不划算，不推荐 
 
 
 
 如何买票快速指南（本文写的很复杂，不想费脑子的小伙伴，可以只读这一段）： 
 
 ---------- 如果你在伦敦停留不超过5天 ---------- 
&#8227; 提前准备带有Contactless功能的银行卡 / 电子设备， 无卡费 ，进出地铁直接刷卡 
&#8227; Zone1地铁单程￡2.9，Off-peak时段￡2.8，当日封顶￡8.9，机场例外， 机场交通直接看这里 
&#8227; 当日封顶是当天刷到这个金额后，继续乘车不再扣除费用；系统自动计算，所以全程不需要额外操作 
 
 ---------- 如果你在伦敦停留超过5天（无跨周） ---------- 
&#8227; 如果停留日期正好在周一至周日内，直接刷Contactless功能的银行卡 / 电子设备， 无卡费 
&#8227; 伦敦有一个当周封顶Weekly Cap，zone1￡44.7，时间按照周一至周日计算，刷到此金额，之后乘车不再扣钱 
&#8227; 没有达到Weekly Cap，仍按照：Zone1地铁单程￡2.9，Off-peak时段￡2.8，当日封顶￡8.9计算 
&#8227; 总之全程系统自动计算，不需要额外操作，省心；机场例外， 机场交通直接看这里 
 
 ---------- 如果你在伦敦停留超过5天（跨周） ---------- 
&#8227; 那么建议办理Oyster Card，卡费￡7，在Oyster中充值7days Travelcard，￡44.7 
&#8227; 7days Travelcard是可以跨周的七天卡，只能储值在Oyster中 
&#8227; 旅行结束后，卡内余额不超过￡10时可退余额，但Oyster卡费不能退 
 
 
 
 什么是牡蛎卡 Oyster Card ？什么是Contactless？ 
&#8227; Oyster Card是伦敦的交通卡，翻译作牡蛎卡，可以用于伦敦基本所有的公共交通 （地铁、公交、DLR、Overground及市区火车） 
&#8227; 卡费￡7，可在地铁站售票机上购买、充值，还可以充值7天通票 （7day Travelcard） 
&#8227; 离开伦敦时，卡内余额可退 （但余额需要小于￡10才可售票机退款） ，￡7卡费不退 
 
&#8227; 伦敦的公共交通还可以直接刷带有Contactless功能的信用卡 / 银行卡 / 电子设备 （比如Apple Pay） 
&#8227; Contactless除了不能充值7day Travelcard，其他计费方式与Oyster Card一样；并且不需要卡费 
&#8227; 需要注意：部分英国外的银行卡可能无法使用；英国外的银行卡还会收取手续费 （但不高，比Oyster Card卡费划算） 
 
-------- 对于短途游客，两者区别 -------- 
&#8227; Oyster Card：有￡7卡费 （不能退） ，可以充值7day Travelcard 
&#8227; Contactless：无卡费 （但非英国卡有手续费，数额小） ，无法充值7day Travelcard 
 
&#8227; 在伦敦停留5天以内：Contactless更划算，不买Oyster Card立省￡7 
&#8227; 在伦敦5天以上（周一至周日内）：Contactless是可以使用Mon-Sun Cap，系统自动扣除，还是Contactless划算 
&#8227; 在伦敦5天以上（跨周 / 不含5天）：Contactless无法充值7day Travelcard，Oyster Card更划算 
 *做算术：比如周三至次周周二，共计7天zone1；Contactless花费￡62.3，Oyster Card充值7day Travelcard仅需￡44.7 
 
 
 
 
 
 
 
 
 伦敦地铁票价解释：单程票 / 当日封顶 / 7day Travelcard 
 *对于游客来说，地铁票价最重要的有下面几种，主要是zone1范围内： 
 单程： zone1区域￡2.9， Off-Peak时段 ￡2.8，即进出地铁刷一次卡的价格 
 当日封顶： Daily Cap，最常用的是zone1 Daily Cap￡8.9 （zone1-2也是￡8.9，所以住在zone2也很方便） 
 * 即你在zone1区域内乘地铁等交通，到达￡8.9后不再扣费；系统会自动计算，不需要在机器上操作 
 
-------- 7天票（适合停留超过5天的票价） -------- 
 7day Travelcard： 7日通票，zone1范围内仅需￡44.7，需自行在机器上储值在Oyster Card中，不适用于Contactless 
 Mon-Sun Cap： 一周封顶，zone1￡44.7，系统自动计算，但限制就是周一至周日，适用于Contactless和Oyster 
 *做算术：Daily Cap是￡8.9，乘以5等于￡44.5；故停留超过5天，7day Travelcard和Mon-Sun Cap就是更划算的选择 
 
 
 
 
 
 注意事项 
&#8227; 下图为刷卡器，乘坐地铁、DLR、Overground，进 / 出均需要刷一次卡 
&#8227; 个别车站出站时可能没有闸机，但也记得找到黄色读卡机刷一下，否则会按照最高票价扣款 
 
 
 
 
 *乘公交仅需要上车刷一次卡，另外，公交单程票为￡1.75 
 
-------- Oyster Card相关 -------- 
&#8227; 余额小于￡10才可以在自动售票机退钱，所以不建议一次充太多钱 
&#8227; 拿到卡后建议第一时间拍照，主要是为了记住卡背面的号码，丢失时可作为挂失凭证 
&#8227; 查余额：大多数读卡机上可以显示余额；自动售票机上刷一次卡也可以查询余额 
 
-------- Contactless相关 -------- 
&#8227; 保证全程使用同一张卡 / 同一个设备，方便计费系统准确计算 
&#8227; 如果使用手机里的Apple Pay等支付方式，请保证电量充足

 牡蛎卡常见问题： 
 时间相关问题： 
 
 Q：伦敦市区交通的Peak time 与 Off-Peak time分别是什么时段？ 
&#8227; Peak time与上下班的高峰时间对应；周一至周五 6.30am - 9.30am 及 4pm - 7pm 
 *上述时间为zone1内部 或 从zone1内向外部方向行进的Peak time；但如果从zone1之外向zone1行进，Peak time只有周一至周五 6.30am - 9.30am 
&#8227; 其余时间均为Off-Peak time，包括周六日全天、节假日 
 
 
 Q：Daily Cap当日封顶 / 7days Travelcard是如何计算时间的？ 
&#8227; 均按照日期来计算一天，但不是零点至零点 
&#8227; 从当日4.30am至次日凌晨4.29am计算 
&#8227; 也就是说，如果你晚上超过零点之后乘坐公共交通，仍算做前一天的当日封顶

 区域相关问题： 
 
 Q：如果车站位于区域交界处，地铁票价格如何计算？ 
&#8227; 采取就近原则，举例说明，Earl's Court位于Zone1和Zone2的交界处 
&#8227; 从Earl's Court前往Zone1景点，按照Zone1区域内收费； 
&#8227; 从Earl's Court前往位于Zone6的希斯罗机场，按照Zone2-6收费 
 
 
 Q：如果购买了zone1-2的7Day Travelcard，要去超出zone1-2的地方怎么办？ 
&#8227; 超出的部分将会在余额中扣除 （首先确保卡中有除了Travelcard之外的余额） 
&#8227; 举例：要从zone1坐地铁去位于zone6的希思罗机场 
&#8227; zone1-2部分还是会使用Travelcard，另外会扣除zone3-6一张单程票的费用 
 
 
 
 
 儿童相关问题： 
 
 Q：儿童在伦敦乘坐地铁等公共交通，如何收费？ 
&#8227; 11岁以下儿童：免费 
&#8227; 11-15岁儿童：半价；但需要买Oyster Card，设置Young Visitor Discount 
&#8227; Young Visitor Discount设置：在任意地铁站找工作人员帮忙，折扣有效期为14天 
&#8227; Young Visitor Discount当日封顶票价也为成人票价的一半 
 
 
 
 
 机场相关问题： 
 
 Q：希思罗机场前往市区的交通可以刷Oyster Card或Contactless吗？ 
&#8227; 机场快线、火车、地铁均可刷Oyster或Contactless；机场大巴不可以 
&#8227; 机场快线 Heathrow Express：刷Oyster或Contactless，全价扣款，单程￡25 （但不推荐刷卡，提前官网买有优惠） 
&#8227; 火车 Elizabeth Line：刷Oyster或Contactless，单程￡12.8 （推荐直接刷；无需提前买票，无优惠） 
&#8227; 地铁：刷Oyster或Contactless，单程￡5.8 （推荐直接刷；机场位于zone6，并且无off-peak票） 
&#8227; 更多信息参考： 希思罗机场到伦敦市区的交通 
 
 
 Q：希思罗机场能买到牡蛎卡吗？ 
A：地铁站可以买到，游客中心也可以买到 
 
 
 Q：盖特威克机场 / 卢顿机场 / 斯坦斯特德机场到市区的交通可以刷Oyster Card或Contactless吗？ 
&#8227; 盖特威克机场：火车可以刷Oyster或Contactless，单程Off-Peak时段￡10.7，Peak时段￡19.2 
&#8227; 卢顿机场 / 斯坦斯特德机：均不可以刷Oyster Card或Contactless，如果计划坐火车，需要单独购买车票 
&#8227; 相关攻略： 盖特威克机场交通 / 卢顿机场交通 / 斯坦斯特德机场机场交通 
 
 
 
 
 公交相关问题： 
 
 Q：伦敦公交如何乘坐？如何买票？票价如何计算？ 
&#8227; 伦敦公交已不接受现金买票，只能刷Oyster Card或者Contactless 
&#8227; 与地铁不同的是，上车只需要刷一次卡，下车无需刷卡 
&#8227; 单程票￡1.75，1小时之内可换乘其他公交，不分区域 
&#8227; 但适用于分区cap当日封顶，比如zone1当日封顶为￡8.9，可以不限次数乘坐此区域的地铁、公交等 
 * 另外，公交还有另一种当日封顶算法，如果你当天只乘坐了公交，当日封顶为￡5.25，且不分区域 
 
 
 
 
 其他问题： 
 
 Q：Oyster Card可以与别人共享吗？ 
&#8227; 不能两人同时使用，乘车时必须一人一张卡；但你的行程结束后，可以转赠给别人 
 
 
 Q：Visitor Oyster Card是什么？ 
&#8227; 本质上也是Oyster Card，使用方法和刷卡票价均相同，￡5押金，有一些餐厅和景点 （不太实用） 的优惠 
&#8227; 但因为无法在伦敦购买，只能邮寄，所以可以不用关注 
 
 
 Q：Day Travelcard是什么？ 
&#8227; 纸质日票，价格是￡16.6，太贵了，不划算，别买 
&#8227; 不如直接使用Oyster Card或Contactless当日封顶，才￡8.9 
 
 
 Q：Oyster Card如何绑定Railcard？有什么优惠？（此问题值得关注！） 
&#8227; 首先，关于Railcard是什么，可以参考攻略： Railcard 英国铁路卡攻略 
&#8227; 如果你已经持有以下种类的Railcard，那么绑定Oyster Card，可以在Off-Peak时段享受1/3的市区交通折扣 
&#8227; 16-25 Railcard / 26-30 Railcard / Senior Railcard可绑定Oyster Card 
&#8227; 具体方法是，带着你的Oyster Card、Railcard，在地铁站找工作人员设置即可 
&#8227; 后续乘车，请随身携带相关Railcard，以备检查；更多信息 参考官网 
 *Family Friends Railcard / Two Together Railcard无法绑定Oyster Card优惠 
 
 
 Q：Oyster Card如何挂失？ 
&#8227; 如果没有所丢失的旧卡背后的号码，则无法挂失；如果有此号码—— 
&#8227; 1、用旧卡号码在Oyster Card官网注册 
&#8227; 2、买一张新卡，需要乘坐一次交通工具 （激活作用） ，等待24小时 
&#8227; 3、在官网你的账号中将旧卡中的余额或通票转入新卡中 
&#8227; 详细步骤参考 官网 
 
&#8227; 所以，Oyster Card到手第一步，请拍下卡背面的号码，丢失时可作为挂失凭证 
 
 
 
 
 
 
 Q：Oyster Card或Contactless多扣钱了，怎么追回？ 
&#8227; 一般可能会因为出站时，没有刷到卡，而多扣钱，可以追会，很方便 
&#8227; 需要在官网或APP注册，按照指示一步步操作即可；详细信息请参考 这里 
 
 
 Q：Oyster Card或Contactless可以支付缆车或船吗？ 
&#8227; 可以；但是独立付款的系统，不参与当日封顶 
&#8227; 缆车具体信息请参考官网： IFS Cloud Cable Car 
&#8227; Uber Boat具体信息请参考： 泰晤士河游船攻略 ，及 River fares 
 
 
 Q：如何查询伦敦地铁站是否有电梯？ 
&#8227; 伦敦地铁因为比较古老，所以并不是所有的地铁站都有电梯 
&#8227; 可以参考 Avoiding stairs Tube guide 
 
 
 Q：伦敦地铁内有手机信号吗？ 
&#8227; 2024年起，伦敦地铁内的手机信号问题已经在慢慢改善 
&#8227; 但部分行驶区间仍然有信号不佳的问题；地铁站是有信号的 
&#8227; 建议提前查好路线，另外车厢内有电子显示屏，会有报站信息

 牡蛎卡购买流程 
&#8227; 大多数自动售票机有中文可以选，这里用英文举例，选择Get New Cards 
 
 
 
 
 
&#8227; 选择购买张数 
 
 
 
 
 
&#8227; 选择充值金额，这里也可以选择充值7 Day Travelcard 
 
 
 
 
 
&#8227; 付款（卡费已涨为￡7），可以选择硬币coins，纸币notes，刷卡，有些机器可能只有这三种选项的其中之一或之二 
 
 
 
 
 
&#8227; 付款成功，取卡 
 
 
 
 
 
 
 
 牡蛎卡充值流程 
&#8227; 先在自动售票机上刷一下卡 
 
 
 
 
 
&#8227; 选择充值金额 
 
 
 
 
 
&#8227; 付款 
 
 
 
 
 
 
 
 
 
&#8227; 再刷一次卡，完成充值交易 
 
 
 
 
 
&#8227; 显示充值成功，以及现有余额 
 
 
 
 
 
 
 
 牡蛎卡退卡流程 
&#8227; 卡内余额少于￡10，才可以在自动售票机上退款 
 
 
 
 
 
&#8227; 先在自动售票机上的黄色读卡处刷一下卡 
 
 
 
 
 
&#8227; 选择退款选项 - Pay as you go refund 
 
 
 
 
 
&#8227; 显示退款金额，点击确认；注意 - 卡费无法退款 
 
 
 
 
 
&#8227; 再刷一次卡完成退款交易 
 
 
 
 
 
&#8227; 取出退回的钱，完成
