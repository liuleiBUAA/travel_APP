 卡迪夫旅游基本信息 
- 卡迪夫 （Cardiff） ，也被翻译成 加的夫，是威尔士的首府，位于南威尔士 
- 旅游资源并不是很丰富，如果要玩儿的话，建议接和 斯旺西 罗西里海滩 一起玩 
- 游览1天足够；另外卡迪夫的酒店数量和性价比都好于斯旺西，更推荐 住在卡迪夫 
 
 
 
 如何前往卡迪夫： 
- 乘坐火车最方便，火车站选择Cardiff Central（ 火车票查询 ） 
- 卡迪夫距离斯旺西1小时 / 布里斯托1小时 / 伦敦2小时火车车程 
 
 
 
 
 
 
 
 
 卡迪夫住哪里最方便 
- 住在市中心最方便，建议靠近火车站Cardiff Central； 查询卡迪夫酒店 
 
 ---------- 卡迪夫市中心酒店推荐 ---------- 
 Clayton Hotel Cardiff （4星，评分8.7分，评价人数5000+，位于卡迪夫火车站旁边） 
 Sleeperz Hotel Cardiff （3星，评分8.3分，评价人数2000+，位于卡迪夫火车站旁边） 
 ibis Cardiff Centre （3星，评分8.0分，评价人数4000+，位于市中心，距离火车站步行15分钟） 
 Jurys Inn Cardiff （4星，评分8.6分，评价人数3000+，位于商业街区） 
 
- 如果想住在卡迪夫湾，那么推荐下面这家酒店 
 voco St. David's Cardiff, an IHG Hotel （5星，评分8.9分，评价人数3800+） 
 
 
 
 
 
 
 
 
 
 卡迪夫地图： 
 - 游览卡迪夫，主要分为两个区域 —— 市中心、卡迪夫湾 
- 市中心前往卡迪夫湾比较远，建议坐公交或打车，车程15分钟 
 
 区域一：卡迪夫市中心 （火车站 / 卡迪夫城堡 / 卡迪夫国家博物馆 / 购物中心） 
 区域二：卡迪夫湾 （看海 / 小红房子） 
 
 
 
 
 
 
 
 区域一：卡迪夫市中心 
 玩多久 / 怎么玩： 
- 最重要的景点是卡迪夫城堡，参观大约需要1-2小时；卡迪夫国家博物馆是免费的，也可以进去逛逛 
- 但因为和伦敦等大城市的历史景点 / 博物馆比起来，卡迪夫的城堡和博物馆确实优势不大，所以均为选去景点 
 
 
 
 
 
 &#10102; 卡迪夫城堡 Cardiff Castle 
- 卡迪夫城堡是一座维多利亚哥特复兴式的中世纪城堡，修建于11世纪，目前的样貌来自维多利亚时代的翻新 
- 城堡的历史非常久远，可以追溯至公元55年，所在地最早被罗马人当作防御地带 
- 自18世纪起，城堡属于比特侯爵，一直传到第五代，因为昂贵的遗产税，第五代侯爵将城堡捐献给了卡迪夫市民 
- 卡迪夫城堡主要参观两个部分，Castle Apartments和Norman Keep

 &#10107; 卡迪夫市场 Cardiff Market 
- 和英国各大城市一样，卡迪夫的市场也卖小吃、新鲜蔬果等等 
- 开放时间为周一至周六8am - 5pm，更多信息可以 参考官网 
- 这里主要要推荐的是市场内一家非常大的黑胶唱片店Kellys Records，爱好音乐的同学绝对要来逛逛

 区域二：卡迪夫湾 Cardiff Bay 
 玩多久 / 怎么玩： 2小时，主要玩法是逛逛海边，看看地标建筑 
 简介： 19世纪时，威尔士作为重要的煤炭输出地，卡迪湾这里聚集了不同国家的人；二战后经济开始萧条；1999年后，卡迪夫湾开始了都市更新计划，现在这里聚集了威尔士议会大厦、千禧中心大剧场、科技馆、大型购物商场，被认为是英国最成功的都市更新计划之一。

卡迪夫湾的地标建筑有下面这些： 
 
 
 
 
 
 &#10102; 达尔广场 Roald Dahl Plass

 &#10103; 小红房子 Pierhead Building 
- 正经应该翻译成皮尔海德大楼，修建于1897年，是英国的一级保护建筑 
- 现在的功能是展览贸易中心 
 
 
 
 
 上图图片来源： Andy Watkins 
 
 
 
 &#10104; 人脸雕塑 Merchant Seafarer's 
- 位于议会大厦前，雕塑面朝地面的一侧是人脸，但从上方看是一艘船的内部 
 
 
 
 
 上图图片来源： Nick Fewings 
 
 
 
 &#10105; 威尔士议会大厦 The Senedd 
- 威尔士议会的办公场所，建筑非常有设计感 
 
 
 
 
 上图图片来源： 议会大厦官网 
 
 
 
 
 上图图片来源： Tidy 
 
 
 
 &#10106; 千禧中心 Wales Millennium Centre 
- 是一座包含了一个大型剧场以及两个小演出厅的艺术中心 
- 中心正立面上雕刻的文字来自威尔士诗人Gwyneth Lewis的诗歌 
- 左边一句是Creu Gwir fel Gwydr o Ffwrnais Awen，翻译成英文Creating truth like glass from inspiration's furnace 
- 右边一句是英文In these Stones Horizons Sing 
 
 
 
 
 上图图片来源： Charlie Seaman 
 
 
 
 &#10107; 挪威教堂 Norwegian Church Arts Centre 
- 非常好看的白色小教堂，竣工于1868年12月，曾经是一座路德宗教堂 
- 19世纪卡迪夫湾聚集了很多挪威人，这座小教堂是当地挪威人社区的宗教场所 
- 现在的作用是一座艺术中心
