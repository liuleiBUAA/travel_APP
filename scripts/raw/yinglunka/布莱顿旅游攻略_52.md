 布莱顿旅游基本信息 
 英文： Brighton 
 玩多久： 布莱顿+ 七姐妹白崖 需要一整天 （可以从伦敦当日往返） ；布莱顿留出1-2小时逛逛海边、吃顿饭即可 
 
 简介： 布莱顿是英格兰南部著名的海滨度假城市，码头改建的游乐场、悠闲的海滩、充满创意和想象的小店、英国Gay Capital的名号，这些让整个城市都充满了平和有爱的气氛，尤其是夏天，白天很长，夕阳很美，特别适合来海边走走。

 布莱顿节日活动 
 布莱顿同性恋大游行 （Brighton Pride） ： 布莱顿作为腐国的Gay Capital，游行规模非常盛大，时间是每年8月初。 （ 详情参考官网 ） 
 布莱顿艺穗节 （Brighton Fringe Festival） ： 英格兰地区最盛大的艺术节，时间大约是每年五月。 （ 详情参考官网 ） 
 
 
 
 
 
 
 布莱顿如何前往七姐妹白崖 
 车程 / 线路： 从布莱顿前往七姐妹游客中心坐公交大约需要1小时，可以乘坐12、12A、12X路公交。 
 车票 / 时刻表： 票价成人单程￡4.4，往返￡6.9；5-13岁儿童半价；时刻表参考 官网 
 出发车站： 布莱顿可以在火车站附近 （车站Brighton Stn D） 、丘吉尔广场附近 （车站Imperial Arcade K） 乘车 
 抵达车站： 七姐妹白崖从Seven Sisters Park Centre这一站下车 
 游览时长： 从公交站至海边大约要走30-40分钟 （途中景色很棒） 加上在白崖附近玩耍的时间请至少预留3-4小时比较合理 
 相关攻略： 《 七姐妹/比奇角白崖攻略 》 
 整体行程： 可以先游览七姐妹，再游览布莱顿，布莱顿返回伦敦的火车一直到深夜都有，并且布莱顿的夕阳很美，还可以吃饭 
 
 
 
 
 
 
 
 
 
 
 
 布莱顿必去景点 
 布莱顿海滩 / 布莱顿码头 
 简介： 从布莱顿火车站出发，向南走大约1km便能来到海滩；海滩最重要的部分是布莱顿码头，建于1899年。 
 
 
 
 
 
 
 
 
布莱顿码头上有餐厅和一座游乐场，游乐场是可以免费进入的。 
 （项目价格在￡2-￡5左右，旋转木马￡3、过山车￡5、充气堡￡2.5，详情参考 官网 ） 
 
 
 
 
布莱顿码头以西还有一座废墟码头，名字叫西码头 （West Pier） ，西码头最初建于1866年，1975年停止使用。2002年的暴风雨摧毁了西码头的部分区域，紧接着2003年又发生了两起火灾，西码头被烧毁成废墟。 
 
 
 
 
 
 
 
 巷子区 / 北巷区 
 简介： 巷子区 （The Lanes） 和北巷区 （North Laine） 是最具布莱顿特色的商业街区，有很多独立小店、餐厅、咖啡馆。下图为北巷区街道，街道更宽，感觉更年轻有活力。 
 
 
 
 
下图为巷子区街道，街道更窄，感觉更精致。 
 
 
 
 
 
 
 
 布莱顿选去景点 
 i360观光塔 
 *门票小贵 
 英文： British Airways i360 
 简介： i360是一座高162米的观光塔，坐落于西码头的海岸边，样子有点像一根筷子套了一个环形的麦片圈，这个环形的观光舱是可以升降的，观光者可以乘坐观光舱升至高空，360度俯瞰布莱顿和周边的海岸线，据说天气好的时候，向西最远可以看到怀特岛，向东最远可以看到比奇角。体验时长大约为20分钟。 
 官网： 参考这里 
 门票： 成人￡16.5 / 学生￡14.05 / 儿童 （4-15） ￡8.25 
 开放时间： 参考这里 
 
 
 
 
 
 
 
 
 
 
 
 沿海电气小火车 
 *适合亲子游 
 英文： Volks Railway 
 简介： Volks Railway是一段沿着布莱顿海岸行驶的小火车，1883年由工程人才Magnus Volk建立，建立的目的是让当地人了解到电力也可以驱动火车。100多年过去了，这套系统依然在顺利运行。小火车复活节前至10月底才有，路线不是很长，单程车程12分钟，大概15分钟一班。 
 官网： 参考这里 
 票价： 成人单程￡3.9 / 成人往返￡5 / 儿童(3-15)单程￡2.4 / 儿童往返￡3.1 
 运营时间： （复活节前至10月底） 周一周五11:30-17:15 / 周二三四 10:30-17:15 / 周六日 10:30-18:15

 皇家行宫 
 *更像是一个地标建筑；大家一般会因为行程紧张，不选择进入参观 
 英文： Royal Pavilion 
 简介： 皇家行宫是乔治四世在他摄政王时期修建在布莱顿的宫殿，外观有点像泰姬陵，强烈受到了印度伊斯兰建筑风格的影响。行宫内部是中西结合的风格，能看到很多华美的中国元素。 
 官网： 参考这里 https://brightonmuseums.org.uk/royalpavilion/ 
 门票： 成人￡15.5；儿童 (5-18) ￡9.5 
 开放时间： 10月至3月10am-5.15pm；4月至9月9.30am-5.45pm；闭馆前45分钟停止进入 
 闭馆： 12月24日2.30pm闭馆；12月25、26日关闭

 班克斯涂鸦 《接吻的警察》 
 *复制品，位置很方便，适合对艺术感兴趣的同学顺路去看
