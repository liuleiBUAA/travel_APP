 康沃尔旅游攻略 Cornwall 
 
 
 
 康沃尔旅游基本信息 
 康沃尔简介： 
- 康沃尔 （Cornwall） 是位于大不列颠岛西南端的半岛，面积为3,563km2，拥有300英里的海岸线 
- 有悬崖、沙滩、文艺的小镇、适合度假的城市、静谧的渔村、历史遗迹等等，是英国最热门的海滨度假地 
- 不过最最受欢迎的还是康沃尔的西南角，以彭赞斯 （Penzance） 和圣艾夫斯 （St Ives） 两座小城为中心 
 
 玩多久： 至少住宿3晚，时间会比较充裕 
 怎么玩： 可以靠公交游览；如果想自驾，但又不想长距离开车，可以考虑 从彭赞斯租车 
 住哪里： 重视交通，推荐 住彭赞斯 （前往各景点公交直达） ；重视景色，推荐 住圣艾夫斯 （与各景点无直达公交） ；两地均有火车站 
 
 如何前往： 
- 自驾：从伦敦出发，开车至彭赞斯 或 圣艾夫斯至少需5小时 （本文主要介绍公共交通，自驾请参考 本文最后一部分 ） 
- 公共交通 （首选） ：乘火车前往 彭赞斯 或 圣艾夫斯，从伦敦出发火车大约5-6小时 （ 火车票查询 ，搜索Penzance 或 St Ives） 
 备注：至彭赞斯有直达火车；至圣艾夫斯的火车需要在St Erth换乘 
 
 
 
 
 
 重点城市：彭赞斯（交通枢纽）、圣艾夫斯（最美小镇） 
 
 
 
 
 
 重点景点：圣迈克尔山（潮汐岛）、兰兹角（英国的天涯海角）、米纳克露天剧场（拥有悬崖海景） 
 
 
 
 
 
 
 
 
 
 
 
 康沃尔交通 / 行程推荐 / 地图 
 - 如果你是自驾，此区域景点之间距离都很近，可以随意安排（可以选择 在彭赞斯租车 ） 
- 这里仅讨论公共交通的行程，景点之间可以靠公交搞定，发车频率相对来说还是比较频繁的 
 
 ----------- 康沃尔公交信息 ----------- 
- 康沃尔公交由 First Group公司 运营，推荐下载FirstBus APP，可以查询路线 / 时刻表 / 买车票 
- 车票：推荐使用FirstBus APP购买两日票￡18或三日票￡23 （每天乘坐超过2次就很划算） 
- 更多票价参考：上车购买 - 一日￡15 / 两日￡20 / 三日￡25 ；APP购买 - 一日￡13 / 两日￡18 / 三日￡23 
 
 
 
 
 夏季的公交是双层露天的~ 
 
 
 
 
 
 ----------- 康沃尔行程推荐 ----------- 
 
 如果你 住在彭赞斯 ，推荐行程： 
Day1：乘火车抵达彭赞斯+纽林海鲜餐厅 
 - 伦敦至彭赞斯火车5.5小时（ 火车票查询 ），入住酒店 
- 接着去旁边小镇纽林吃网红海鲜餐厅 Mackerel Sky Seafood Bar（步行半小时，沿海走；或公交15分钟） 
 
Day2：兰兹角+露天剧场 
 - 早上兰兹角（1-2小时），中午可以选择在兰兹角吃饭，也可以选择在下一站米纳克露天剧场吃饭，均为海景餐厅 
- 下午参观露天剧场（2-3小时，不要错过旁边的海滩Porthcurno Beach） 
 
Day3：圣迈克尔山+圣艾夫斯 
 - 首先 查询圣迈克尔山的潮汐时间 ，建议在退潮或涨潮的时候去比较好玩；预留半天（不上岛的话大概1-2小时） 
- 剩下的时间留给圣艾夫斯，逛逛海滩、吃吃海鲜，比较悠闲 
 
Day4：离开 
 
 
 
 如果你 住在圣艾夫斯 ，推荐行程： 
Day1：乘火车抵达圣艾夫斯+游览圣艾夫斯 
 - 伦敦出发火车5-6小时（ 火车票查询 ），入住酒店 
 
Day2：兰兹角+露天剧场 
 - 首先需要乘A17路公交至彭赞斯，再换乘公交A1路 
- 早上兰兹角（1-2小时），中午可以选择在兰兹角吃饭，也可以选择在下一站米纳克露天剧场吃饭，均为海景餐厅 
- 下午参观露天剧场（2-3小时，不要错过旁边的海滩Porthcurno Beach） 
- 结束参观后，乘坐A1路公交，可以在纽林下车，吃网红海鲜餐厅Mackerel Sky Seafood Bar 
- 吃完饭坐公交先返回彭赞斯，再换乘A17路返回圣艾夫斯 
 
Day3：圣迈克尔山+ 圣艾夫斯 
 - 首先 查询圣迈克尔山的潮汐时间 ，建议在退潮或涨潮的时候去比较好玩 
- 前往圣迈克尔山，必须在彭赞斯换乘公交 
- 其余的时间可以继续在圣艾夫斯逛逛吃吃，或者推荐去Carbis Bay海滩逛逛（圣艾夫斯乘坐小火车3分钟可抵达） 
 
Day4：离开

 康沃尔酒店推荐 
 
 主流选择： 
- 彭赞斯 （ 查询全部酒店 ） or 圣艾夫斯 （ 查询全部酒店 ） 二选一，均可乘火车抵达 
- 彭赞斯的优点是交通枢纽，兰兹角 / 露天剧场 / 圣迈克尔山都可以乘公交直达；缺点是本身没有圣艾夫斯好玩 
- 圣艾夫斯的优点是小城本身很好玩；缺点是去兰兹角 / 露天剧场 / 圣迈克尔山需要在彭赞斯换乘公交

 &#10103; 圣艾夫斯 St. Ives 返回地图 
 必读详细攻略： 《 圣艾夫斯旅游攻略 》 
 预定： 圣艾夫斯酒店 
 如何前往： 彭赞斯乘公交A17路32分钟可抵达；或乘火车直接抵达 
 简介： 圣艾夫斯（英语：St. Ives）是康沃尔最有名的小镇；拥有可爱的沙滩、美术馆、餐厅、小店，艺术氛围浓厚，景色也是一级棒；大多数酒店都拥有海景房间，非常适合度假。

 ----------- 1- 圣艾夫斯逛吃 / 海滩 / 参观泰特美术馆 ----------- 
 圣艾夫斯市区一共有四个主要海滩： 
Porthmeor Beach（最热门 / 必去）, Porthgwidden Beach（最袖珍） 
Harbour beach（最繁华 / 必去）, Porthminster Beach（最清静 / 靠近火车站） 
 
 
 
 
 
 推荐行程如下：（可以不完全按着走，随意一些） 
 
 
 
 
 
 &#10102;观景台 The Malakoff：紧挨着公交站，下车步行不到1分钟可抵达 
 
 
 
 
&#10103;海滩 Harbour beach：当地的渔船停靠的海滩，是最繁华的海滩，是在圣艾夫斯觅食的主要地点（ 查看美食推荐 ） 
 
 
 
 
&#10104;海滩 Porthgwidden Beach：夹在The Island和Harbour Beach之间的袖珍小海滩，特色是有一排小房子（图片来自 官网 ） 
 
 
 
 
&#10105;小教堂 St. Nicholas Chapel：位于圣艾夫斯最北端的半岛（The Island）；这里是一个制高点，可以欣赏海景 
 
 
 
 
&#10106;海滩 Porthmeor Beach：获奖海滩，因为位置便利，是圣艾夫斯最受欢迎的海滩；泰特美术馆位于这个海滩 
 
 
 
 
&#10107;泰特美术馆 Tate St Ives：门票￡10.50，开放时间 参考官网 ，是一家可以看海的美术馆；咖啡馆超级美（图片来自 泰特美术馆instagram ） 
 
 
 
 
&#10108;海滩 Porthminster Beach：火车站所在的海滩，呈月牙形状；也是获奖海滩，但因为距离繁华区域（港口海滩）有点距离，较清静（图片来自 官网 ） 
 
 
 
 
 
 
 
 ----------- 2- 乘坐海岸小火车 游览Carbis Bay海滩（选去） ----------- 
 注意：此段海岸小火车包含在 从伦敦坐火车前往圣艾夫斯 的火车行程中，如果你从伦敦坐车至圣艾夫斯，则不需要单独体验海岸小火车 
 
 2-3小时行程推荐： 
- 可以先乘小火车从St Ives至St Erth，10分钟车程，欣赏海景 
- 再立刻反方向乘坐，至Carbis Bay下车（小火车1小时2班） 
- 游览Carbis Bay，可以在沙滩餐厅喝点东西（1小时左右） 
- 乘小火车返回St Ives（3分钟车程）

 &#10106; 圣迈克尔山 St Michael's Mount 返回地图 
 必读详细攻略： 《 圣迈克尔山旅游攻略 》 
 如何前往： 彭赞斯乘公交U4路14分钟可抵达圣迈克尔山所在的小镇Marazion 
 简介： 圣迈克尔山是位于康沃尔的一个潮间岛，位于小镇Marazion；这个小岛与陆地之间由一条窄窄的堤道相连，退潮时可以通过堤道步行上岛，涨潮时，海水会淹没堤道，非常有意思；圣迈克尔山与法国的圣米歇尔山非常类似，两座潮间小岛隔着英吉利海峡遥遥相对 
 
 圣迈克尔山怎么玩 / 玩多久： 半天 
1 - 体验不同的上岛方式 - 步行 or 坐船 （ 查询潮汐时间 ，推荐涨潮时刻前往；步行免费，坐船￡2.5，仅需10分钟） 
2 - 上岛参观 - 城堡 花园 （买门票区域 - 城堡成人￡14；花园成人￡10） 
3 - 在景观餐厅吃饭休息 （选去） 
 
 
 
 
 
 
 ----------- 1 - 体验不同的上岛方式 - 步行 or 坐船（1-2小时） ----------- 
 连接圣迈克尔山的步道，每天仅露出海水4小时；打开 官网潮汐查询链接 ，输入日期，CAUSEWAY CLOSES的时刻便是涨潮的时间 
 
 落潮时，可以步行上岛，步道长500米，大概走15分钟 
 
 
 
 
 涨潮时，可以坐船上岛，10分钟船程；船票成人￡2.5，儿童（16岁以下）￡1.5，5岁以下免费 
坐船参考视频： 30天环游英国 - NO.14 城堡巨人的心脏什么样？魔力圣迈克尔山 ，UP主是MINO直豆豆，片长3分43秒 
 
 
 
 
 
 涨潮时还可以体验在水中的步道上走一走，但一定要注意安全，潮水来势会比我们想象的快，不要走太远

 康沃尔自驾选去地点 
- 自驾前往康沃尔，车程都比较长，比如从伦敦出发，直接开到圣艾夫斯 / 彭赞斯，都至少需要5小时 
- 下面推荐两个同样位于康沃尔的景点，适合在沿途中顺路游览： Tintagel Castle 廷塔哲城堡 、 Eden Project 植物园 
- 如果想打卡英国大陆最南点，还可以前往 Lizard Point Kynance Cove 
 
- 另一个适合放在自驾行程中的景点是 侏罗纪海岸 ，可以更合理地拆分行程； 
- 侏罗纪海岸本身需要玩大半天，建议在附近的 Weymouth 或 Bournemouth 住一晚 
 
 
 
 
 
 
 
 
 
 Tintagel Castle 廷塔哲城堡 
 简介： Tintagel Castle是位于康沃尔北部海岸的一座城堡废墟，建于1233年，和亚瑟王传说有着密切的关系。14世纪后城堡荒废，直至维多利亚时期成为著名的观光地。城堡废墟坐落在拥有壮观海景的悬崖上，景点尽头有一座亚瑟王雕塑。 
 
 官网： 参考这里 
 门票： 成人￡14.5，学生￡13.1，儿童 （5-17） ￡8.7；English Heritage会员免费 
 开放时间： 参考这里 
 参观时长： 2-3小时 
 自驾： 至彭赞斯 / 圣艾夫斯1.5小时车程；停车场位于Tintagel小镇，步行至城堡需要10分钟

 Eden Project 植物园 
 简介： Eden Project 是位于康沃尔的一个巨大的植物园，由八座温室组成，每个温室都模拟了不同的生态系统，有热带生物群、地中海生物群等等，整个植物园占地面积差不多有30个足球场大小，温室大小也差不多是世界上最大的。Eden Project于2001年开始对外开放，是建在废弃的矿山上，所以也颇具再生可持续发展的意义。 
 
 官网： https://www.edenproject.com 
 门票： 分淡旺季，成人￡27.5 - 35；学生￡22.5 - 30；儿童 （5-16岁） ￡10 （4岁及以下免费） 
 开放时间： 参考这里 
 参观时长： 官方建议3-4小时 
 自驾： 至彭赞斯 / 圣艾夫斯1小时车程；Eden Project可免费停车 
 公共交通 ：最近的火车站为St Austell （ 火车票查询 ） ；之后乘公交半小时 （可通过google map查询） 。

 Lizard Point Kynance Cove 英国大陆最南端 
 简介： Lizard Point 是英国陆地的最南点，附近还有一个非常好看的小海滩可以一起游览Kynance Cove。 
 玩多久： 2小时-半天 
 
 自驾： 
- 可以选择住在圣艾夫斯或者彭赞斯期间开车前往，车程均为一小时左右； 
- 也可以选择离开时顺路前往，下一站可以选择 住在法尔茅斯 （Falmouth） ，玩半天 
 
 
 
 
 
 两个景点之间的交通： 
- 徒步：Kynance Cove位于Lizard Point西北3.5km处，之间是著名的徒步路线，单程需要走45分钟-1小时 
- 自驾：开车大约15分钟，两景点均有停车场 
 
 
 
 
 
 
 Lizard Point： 景点有咖啡馆、停车场、灯塔
