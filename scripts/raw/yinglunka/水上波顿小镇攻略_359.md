 水上伯顿旅游攻略 Bourton-on-the-Water 
 
 
 
 &#8227; 水上伯顿 （Bourton-on-the-Water） 是科茨沃尔德 （Cotswold） 最热门的村子 
&#8227; 疾风河 （River Windrush） 从村子中穿过，河畔是草地和绿树，河水很浅，夏天可以下水玩耍 
&#8227; 河畔建有黄色石头小房子，有很多咖啡馆、餐厅、礼品店，环境非常悠闲 
 
 玩多久： 非常建议游览整个科茨沃尔德时， 住在水上伯顿 
&#8227; 假设住在水上伯顿，如果全程公共交通，那么建议住2-3晚，可以完整游览科茨沃尔德的精华小镇 
&#8227; 如果是自驾，建议至少住1晚，用2天时间游览科茨沃尔德 
&#8227; 如果住宿地没有选在水上伯顿，仅仅是坐车去玩，建议至少预留大半天 （1小时游览本镇，2-3小时徒步游览Lower Slaughter） 
 
 
 
 
 图片来源： Jonathan 
 
 
 如何前往水上伯顿 
 第一步：先坐火车抵达Moreton-in-Marsh 
&#8227; 下图红圈是科茨沃尔德，首先应该先乘坐火车前往Moreton-in-Marsh， 火车票查询 
 （或者坐到Cheltenham也可以，但没有Moreton-in-Marsh方便） 
 
 
 
 
 
 第二步：乘坐801公交抵达水上伯顿 
&#8227; Moreton-in-Marsh至水上伯顿乘801只需30分钟，可在火车站门口坐公交， 查看车站位置 
&#8227; 801路信息：车票￡3，大约1小时1班，周日2小时1班， 时刻表 
 （Cheltenham至水上伯顿乘801需1小时，且从火车站还需要换乘公交10分钟才能抵达801车站， 查看车站位置 ） 
 
 
 
 
 
 
 
 
 
 
 水上伯顿酒店推荐 
&#8227; 水上伯顿是科茨沃尔德住宿的最佳选择，原因如下 
&#8227; 是 最热门的小镇 ，景色好，并且可以在一日游游客退去后体验安静的水上伯顿 
&#8227; 生活设施方便 ，餐厅多，还有一家非常大的Co-operative超市 
&#8227; 交通方便 ，801路公交连接火车站，班次较多，且周日不停运 
&#8227; 查询所有水上伯顿酒店

 水上伯顿如何前往其他小镇 / 行程推荐 
 公交信息： 请参考 科茨沃尔德公交攻略 
 其他小镇信息： 请参考 科茨沃尔德旅游攻略 、 科茨沃尔德酒店攻略 
 
&#8227; 本行程需住在 Bourton-on-the-Water 
&#8227; 注意周日的安排：仅801路公交周日运营，其他公交周日停运 
 
 Day1： 早上乘火车抵达Moreton-in-Mash （伦敦1.5小时，牛津40分钟） 
&#8227; 乘801半小时抵达Bourton-on-the-Water，入住酒店 
&#8227; 下午游览Bourton-on-the-Water 
 
 Day2： 乘801路+1路抵达Broadway （在Moreton-in-Mash换乘） ，交通预计1.5小时 
&#8227; 以Broadway Tower为目的地徒步，往返预计2-3小时 
&#8227; 从Broadway乘1路 / 606路前往Chipping Camden，车程20分钟 
&#8227; 游览Chipping Camden小镇，1小时左右 
&#8227; 乘坐2路 + 801路返回Bourton-on-the-Water （在Moreton-in-Mash换乘） ，交通预计1.5小时 
 
 Day3： 乘855路前往Bibury游览 （车次非常少，一般坐10am的班次，半小时抵达） 
&#8227; Bibury游览只需要半小时，返程时刻表 参考这里 
&#8227; 返回Bourton-on-the-Water后，下午可以徒步去Lower Slaughter，往返大约1.5-2小时 
 
 Day4： 乘801路至Moreton-in-Mash，30分钟；乘火车离开 
 
 
 
 
 
 
 
 
 水上伯顿怎么玩（本镇） 
&#10102; 沿着疾风河散步 / 休闲 / 拍照 （1小时） 
&#10103; 徒步前往Lower Slaughter （往返2-3小时） 
 
&#8227; 如果你 住在水上伯顿 ，那么&#10102; 抽空体验就行，&#10103; 可以在不容易安排去其他小镇的公交行程时体验 （因为公交班次少） 
&#8227; 如果不住在水上伯顿，那么建议先体验&#10103; ，返回水上伯顿后等车时体验&#10102; ，加上吃饭时间，全程预留大半天 
 
 下图为水上伯顿地图 
 
 
 
 
 
 
 &#10102; 沿着疾风河散步 / 休闲 / 拍照（1小时） 
&#8227; 最精华的路段是从801车站至鸟园这一段，纯步行大约只需7分钟 
&#8227; 可以预留一小时，拍拍照、吃个冰激淋、在浅浅的河水中泡泡脚

 &#10103; 徒步前往Lower Slaughter（往返2-3小时） 
&#8227; 整个过程很轻松，单程只需要30-40分钟就能走到Lower Slaughter 
&#8227; 会途径一个很可爱的马场 
&#8227; Lower Slaughter村很小，但也非常美，可以预留30分钟至1小时逛一下 
&#8227; 时间精力更多的同学，可以继续徒步前往Upper Slaughter

 水上伯顿选去景点 / 项目 
&#8227; 以下景点都比较适合带小朋友，成人前往可能会觉着有点无聊 
&#8227; 各景点位置可 返回地图 查看 （都在游客中心步行10分钟范围内） 
 
 
 模型村 The Model Village 
&#8227; 模型村是以水上伯顿为原型，以1：9的比例建的一个迷你小镇 
&#8227; 范围涵盖了从汽车博物馆到Old New Inn这一区域 
&#8227; 模型村是由Old New Inn的一位领主建立的，于1937年正式对外开放参观 
&#8227; 整个迷你小镇的房子也是由当地特产的Cotswold Stone所建成 
&#8227; 官网： 参考这里 
&#8227; 开放时间：夏季10am-5.30pm ；冬季10am-3.30pm；圣诞节休息 
&#8227; 门票：成人￡4.5，儿童 （3-13岁） ￡3.5，3岁以下免费，老人 （60岁以上） ￡4 
 
 
 
 
 图片来源： Karen Roe 
 
 
 
 鸟园 Birdland 
&#8227; 鸟园建于1957年，面积大概有9英亩，现在园子里大概有130多种鸟 
&#8227; 有企鹅、火烈鸟、鹦鹉、鹈鹕、鹳、猫头鹰、犀鸟等等 
&#8227; 除了鸟类，园子里也有一些其他的小动物比如兔子、狐狸、蛇 
&#8227; 每天还会有喂企鹅和火烈鸟的展示参观 
&#8227; 官网： 参考这里 
&#8227; 开放时间：10am - 5pm ，4pm停止进入 
&#8227; 门票：成人￡14.95，儿童 （3-15岁） ￡11.5，3岁以下免费，老人 （60岁以上） ￡13.95 
 
 
 
 
 图片来源： Karen Roe 
 
 
 
 
 
 图片来源： 鸟园官网 
 
 
 
 汽车博物馆 The Cotswold Motoring Museum 
&#8227; 科茨沃尔德汽车博物馆位于镇中心，收藏有20世纪的复古汽车、复古摩托车、模型等等 
&#8227; 官网： 参考这里 
&#8227; 开放时间：10am – 6pm 
&#8227; 门票：成人￡9.5，儿童 （5–16岁 ） ￡6.5，5岁以下免费 
 
 
 
 
 图片来源： Nilfanion ｜ Elliott Brown 
 
 
 
 租自行车 
&#8227; 在水上伯顿租自行车骑行也是很棒的玩法儿 
&#8227; 可以去 Slaughter村 或者周边的田野，自行车行会推荐路线。 
&#8227; 车行官网： Hartwells Cotswold Cycle Hire 
&#8227; 运营时间：夏季10am-6pm，周日10.30am-5.30pm；冬季10am-5pm，周日11am-4pm 
&#8227; 租金：全天成人￡18 / 儿童 （16岁以下） ￡12；半天 （3小时内） 成人￡13 / 儿童￡9 
&#8227; 位置：位于镇中心疾风河畔，定位Hartwells Cotswold Cycle Hire
