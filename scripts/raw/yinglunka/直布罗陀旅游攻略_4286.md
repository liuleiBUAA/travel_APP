 直布罗陀旅游基本信息 
 直布罗陀英文： Gibraltar 
 
 简介： 直布罗陀是英国官方承认的第14个英国海外领土，在英国上学、生活的小伙伴们即使没有申根签证，也可以去玩儿；位于西班牙南端，与北非摩洛哥之间由直布罗陀海峡相隔，海峡连接地中海与大西洋，所以直布罗陀的位置极具战略意义；直布罗陀也是英国海外领土中面积最小的一块，约为6平方千米，南北长约4.6公里，东西宽约1.2公里，人口三万。直布罗陀还是免税区，走之前不要忘记买买买。 
 
 玩多久： 至少住3晚 （有两个完整的白天， 参考行程 ） ； 直布罗陀酒店查询 
 
 直布罗陀巨岩是地标，占据了直布罗陀大部分的面积

 前往直布罗陀需要什么签证？ 
- 持有中国护照，以下两种情况，满足其一，即可入境直布罗陀： 
- 情况一：持有效期为6个月或以上的多次英国往返签证 
- 情况二：持多次往返申根签证，最多可以停留21天；如果申根有效期少于21天，则最多可停留7天。

货币：英镑、欧元都可以用

 如何前往直布罗陀？ 
- 直布罗陀有机场Gibraltar International Airport，三字代码为GIB 
- 伦敦、曼彻斯特、爱丁堡均有直飞直布罗陀的航班，航程大约3小时 
 
 
 
 
 
- 局部放大，从西班牙可以自驾或步行入境 
 
 
 
 
 
 
 
 直布罗陀机场交通 
- 直布罗陀太小了，所以去酒店建议直接打车 
- 如果想坐公交，那么可以选择5路 / 10路，能直达Ocean Village、主街等热门地点， 查看路线图及票价 
 
 
 
 直布罗陀住哪里 / 酒店推荐 
- 直布罗陀很小，所以住在任意地方都很方便，打车距离机场很近 
- 最繁华的区域是主街和Ocean Village附近

 直布罗陀景点地图 / 行程推荐 
Day 1：假设中午抵达，下午逛逛 &#10102;主街 购物，熟悉下环境，傍晚前去 &#10104;欧罗巴角 （拍照停留1小时）

 直布罗陀公交路线 / 车票 / 日票 
- 游览直布罗陀，大部分靠步行，然后记住几条比较重要的公交路线即可 
- 市中心公交总站：Market Place，位于主街最北端 
- 5路 / 10路：连接机场和市区 
- 2路：连接Market Place和欧罗巴角，全程大约15分钟车程 
- 4路 / 8路：前往Catalan海滩 
 
- 直布罗陀的公交由两家不同的公司运营，所以票价也略有区别，日票不通用 
- CityBus ：5路 / 10路，单程1.4英镑（2.1欧元） 
- GibraltarBus ：1-4路，7-9路，单程1.8英镑（2.4欧元），日票2.5英镑（3.3欧元） 
- 比较推荐去欧罗巴角、Catalan海滩当天买GibraltarBus公司的日票，除了5路/10路不能坐，其他班次都ok 
- 公交大约10-20分钟一班，上车先进买票即可

 直布罗陀必去景点 / 景点地图 / 行程推荐 
 
 &#10102; 主街 Main Street 返回地图 
 简介： Main Street是直布罗陀最重要的商业步行街，直布罗陀是免税区，购物是必不可少的。主街北起大炮台广场 （Grand Gasemates Square） ，南至Southport Gates，长达约1.2km，如果中间不停留，全程步行大约需要15-20分钟。需要注意的是，周日大部分商店停业休息，安排购物建议避开周日。

 ---------- 出海看海豚 ---------- 
 简介： 直布罗陀近海海域非常容易看到海豚，出海看海豚也是必须体验的项目。出海时长一般为1-1.5小时，取决于当天是否容易找到海豚。因为天气原因活动取消，或者当天没有看到海豚，公司都会补偿一张票，择日免费参加，所以比较建议尽量将此项目安排在行程靠前的时间，灵活性更大。目前有三个公司运营此项活动，集合地点均在Ocean Village。 
 
 Dolphin Adventure： 查询官网

 Dolphin Safari： 查询官网 
- 成人￡30，儿童 （12岁以下） ￡20 
 
 Neptune Marine： 查询官网

 &#10105; 直布罗陀巨岩缆车 Rock of Gibraltar 返回地图 
 简介： 直布罗陀大部分的面积被一座山峰占据，此山被称为直布罗陀巨岩，海拔426米，被认为是海格力斯之柱。乘坐缆车登顶巨岩是直布罗陀最不可错过的项目，山顶有欧洲唯一的野生猴子种群——直布罗陀猕猴（当地人称为apes）。山顶缆车站有观景台，景色极佳，能近距离看到山峰、俯瞰直布罗陀西海岸主城区、东海岸小沙滩，还能远眺摩洛哥、西班牙，一眼望三国。 
 
 如何玩 / 玩多久： 
- 大多数同学会仅选择在山顶缆车站观景台观景 / 拍照 / 喝咖啡，预留1.5-2小时； 
- 山上有很多景点 （岩洞 / 观景台 / 炮台等） ，如果计划游览，则需要预留更多时间，参考 选去景点 
 
 缆车官网： 参考这里 
 票价 - 往返缆车票： 成人￡17；儿童 （5-12岁） ￡8；学生￡15.5 （另有包含山顶景点的套票，参考下文 选去景点 ） 
 车程 / 发车频率： 缆车单程6分钟，山顶缆车站海拔412米，大约每10分钟一班 
 开放时间： 春夏9.30am - 7.15pm （下行末班7.45pm） ；秋冬9.30am - 5.15pm （下行末班5.45pm） 
 注意： 天气恶劣时，缆车可能停运，可以关注官方Twitter @CableCarGib 查看实时信息 
 
 如何前往山底缆车站： 
- 导航至：Cable Car Base Station 
- 方法一：从主街最南端出发，步行5分钟即可抵达 
- 方法二：市中心更远的地方出发，可以坐公交 
- 方法三：从边境线附近出发，有免费接驳车 （乘坐地点搜索Calypso Transport Ltd，具体信息 参考官网 ）

 直布罗陀选去景点 
 Nature Reserve 巨岩自然保护区 
- 整个直布罗陀巨岩都是保护区的范围，需要购买Nature Reserve的门票，一般买缆车票的时候会有套票选项 
- 凭套票，就可以游览保护区内的景点了，还能顺便在山路上走走，景色不错 
- 保护区有三个入口：山顶缆车站，摩尔人城堡入口 （北） ，Jews Gate （南） 
- 建议以山顶缆车站为起点，一路往下玩儿，回看前文 - 巨岩缆车信息 
 
 缆车+保护区套票价格： 
缆车单程+保护区：成人￡28；儿童 （5-12岁） ￡18.5；学生￡26.5 
缆车往返+保护区：成人￡30；儿童 （5-12岁） ￡18.5；学生￡28.5

 B - 洞穴 St Michael's Cave 
简介：直布罗陀巨岩上分布有很多洞穴，St Michael's Cave是其中最大、最热门的一个；据说这些洞穴是无底洞，与非洲相连，相传直布罗陀的猴子是通过这些洞穴中从非洲过来的。二战期间，St Michael's Cave是一个备用的急救医院，现在被改建成了礼堂。前两年，St Michael's Cave又进行了一番改造，加上了灯光投影装置，灯光表演名为The Awakening，意在通过灯光唤醒沉睡的岩石时钟，讲述岩石层层叠叠的历史故事。灯光表演每20分钟上演一次，感兴趣的同学可以先参考 这个视频 。

 D - 摩尔人城堡 Moorish Castle 
简介：最早修建于 1160，是巨岩上的防御工事，西班牙人统治时期，部分建筑被摧毁。摩尔人城堡的庭院直至2010年之前，都一直作为当地的监狱。
