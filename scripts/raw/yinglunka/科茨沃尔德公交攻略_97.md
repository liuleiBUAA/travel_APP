 科茨沃尔德公交攻略 
 
 
 
 &#8227; 科茨沃尔德 （Cotswold） 被评为是英国最美乡村，是一大片区域 
&#8227; 区域内分布着很多村镇，主要玩法是游览村镇、徒步欣赏田园风光。 
&#8227; 交通可以靠公交解决，但需要提前认真计划 
&#8227; 相关攻略： 科茨沃尔德旅游攻略 ， 科茨沃尔酒店住宿攻略 
 
 
 注意事项： 
&#8227; 科茨沃尔德公交班次不多，出发前需要提前查好时刻表 
&#8227; 重要班次时刻表： 801路 / 855路 / 606路 ， 1路 / 2路 
&#8227; 周日仅801路公交运营，其他班次周日不运营 ；请提前计划 
 
 
 公交车票 / 日票： 
&#8227; 科茨沃尔德公交由两家不同公司运营，其中 Pulham‘s Coaches 的路线覆盖更广 
&#8227; Pulham单程票￡3 （部分短途少于￡3） ，日票成人￡8.5，日票儿童￡6.5 （5-15岁） ，5岁以下免费 
&#8227; 801路 / 855路 / 606路均为Pulham公司巴士，可使用日票，上车购买或下载Pulham APP （价格更便宜一些） 
&#8227; 另一家公司是 Stagecoach ，1路 / 2路为此公司大巴，不能使用上述通票；单程￡2.5起 
 
 
 如何前往科茨沃尔德 / 住哪里： 
&#8227; 先乘坐火车前往Cheltenham或Moreton-in-Marsh， 火车票查询 
&#8227; 更推荐坐火车至Moreton-in-Marsh，交通更方便，风格更田园 
&#8227; 再从这两个小镇，乘公交前往其他观光小镇 
 
&#8227; 最推荐 住在Bourton-on-the-Water ：景色好，交通便利 
&#8227; Stow-on-the-Wold 是旺季时期的备选项 
&#8227; Moreton-in-Marsh 适合假期短，更注重交通的小伙伴 
&#8227; 相关攻略： 科茨沃尔德酒店住宿攻略 
 
 
 科茨沃尔德热门公交线路图 / 公交行程推荐 
&#8227; 本行程需住在 Bourton-on-the-Water 
&#8227; 注意周日的安排：仅801路公交周日运营，其他公交周日停运 
 
 Day1： 早上乘火车抵达Moreton-in-Mash （伦敦1.5小时，牛津40分钟） 
&#8227; 乘801半小时抵达Bourton-on-the-Water，入住酒店 
&#8227; 下午游览Bourton-on-the-Water 
 
 Day2： 乘801路+1路抵达Broadway （在Moreton-in-Mash换乘） ，交通预计1.5小时 
&#8227; 以Broadway Tower为目的地徒步，往返预计2-3小时 
&#8227; 从Broadway乘1路 / 606路前往Chipping Camden，车程20分钟 
&#8227; 游览Chipping Camden小镇，1小时左右 
&#8227; 乘坐2路 + 801路返回Bourton-on-the-Water （在Moreton-in-Mash换乘） ，交通预计1.5小时 
 
 Day3： 乘855路前往Bibury游览 （车次非常少，一般坐10am的班次，半小时抵达） 
&#8227; Bibury游览只需要半小时，返程时刻表 参考下文 
&#8227; 返回Bourton-on-the-Water后，下午可以徒步去Lower Slaughter，往返大约1.5-2小时 
 
 Day4： 乘801路至Moreton-in-Mash，30分钟；乘火车离开 
 
 
 
 
 
 
 
 
 科茨沃尔德热门公交线路 
 801路公交 
 简介： 最热门/班次最多，连接火车站小镇Cheltenham / Moreton-in-Marsh和最热门村庄Bourton-on-the-Water 
 运营公司： Pulham‘s Coaches 
 时刻表： 参考这里 ；大概1小时1班，周日2小时1班 
 车票： 单程￡3，可使用Pulhams日票成人￡8.5 / 儿童￡6.5 
 路线 / 车程： 如下图 （Cheltenham 至 Bourton-on-the-Water大约1小时，Moreton-in-Marsh 至 Bourton-on-the-Water大约0.5小时） 
 
 
 
 
 
 
 
 855路公交 
 简介： 连接Bourton-on-the-Water和Bibury，但班次非常非常少 
 运营公司： Pulham‘s Coaches 
 车票： 单程￡3，可使用Pulhams日票成人￡8.5 / 儿童￡6.5 
 路线 / 车程： 如下图，Bourton-on-the-Water至Bibury大约30分钟 
 
 
 
 
 
 时刻表： 参考这里 ；周日休息 
&#8227; 研究过855路时刻表就会发现，时间合适的班次非常少 
&#8227; 最合适的去程班次10am从Bourton-on-the-Water出发，10.34am抵达Bibury；Bibury非常小，半小时可游览完 
&#8227; 返程可以坐11.17am从Bibury出发的班次，11.37am在Northleach下车等待换乘801，返回Bourton-on-the-Water 
&#8227; 其他方案：打车 / 包车往返大概￡50， 参考这里 ；或 从伦敦跟团 
 
 
 
 
 
 
 
 
 
 
 
 606路公交 
 运营公司： Pulham‘s Coaches 
 时刻表： 参考这里 ；周日休息 
 车票： 单程￡3 
 注意事项： 606路班次也很少，可以和1路/2路互补乘坐 
 路线 / 车程： 如下图 
 
 
 
 
 
 
 
 1路 / 2路公交

 运营公司： Stagecoach ；和上述801 / 855 / 606是不同公司，所以不能通用日票 
 时刻表： 参考这里 ；周日休息 
 车票： 单程￡2.5

 其他常见问题 
 Q：Cheltenham公交站在哪里？ 
&#8227; Cheltenham作为科茨沃尔德的入口之一，搞明白在哪里坐公交是很重要的 
&#8227; 重点路线为801路，连接Bourton-on-the-Water 
&#8227; 801路公交站距离Cheltenham火车站大约2km，可以在火车站门口坐公交或打车 
&#8227; 801路公交站可以导航输入Royal Well Bus Station 
&#8227; 公交：乘D路 / E路，10分钟左右车程，在Chapel Walk Set Down Only或George Hotel站下车，再步行5分钟 
 
 
 
 
 
 
 
 Q：Moreton-in-Mars公交站在哪里？ 
&#8227; Moreton-in-Mars同样也是科茨沃尔德的入口之一，火车站和镇中心都有公交站 
&#8227; 如果你是从火车站抵达 / 离开，可以在Moreton in Marsh, Station这一站乘公交 （比Cheltenham方便很多！） 
&#8227; 如果你是从Bourton-on-the-Water前往Chipping Camden或Broadway，可在Corn Exchange换乘 （801路换乘1路2路） 
 
 
 
 
 
 
 
 Q：不幸遇到周日，很多公交停运怎么办？ 
&#8227; 801路在周日仍然运行，可以抵达Bourton-on-the-Water 
&#8227; 可以在周日这一天安排游览Bourton-on-the-Water本村，以及去Lower Slaughter徒步 
&#8227; 周日前往其他村，可以靠打车 / 包车解决，参考 科茨沃尔德打车攻略
