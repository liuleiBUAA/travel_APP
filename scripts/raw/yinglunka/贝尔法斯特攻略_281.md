 贝尔法斯特旅游攻略——北爱尔兰 / 巨人之路 / 黑暗树篱 
 
 
 
 &#8227; 贝尔法斯特 （Belfast） ，北爱尔兰首府，位于整个爱尔兰岛的东北海岸 
&#8227; 泰坦尼克号在这里建造并且起航，为了纪念这艘沉船，贝尔法斯特建造了世界上最大的泰坦尼克号展馆 
&#8227; 贝尔法斯特城市本身旅游资源并不丰富，但附近的巨人之路、黑暗树篱等景点值得一去！ 
 
 玩几天： 3天，其中预留一天可参加： 黑暗树篱 / 巨人之路 / 卡里克索桥一日游 
 *除了上面的一日游，《权力的游戏》粉丝请不要错过2022年最新开放的 片场之旅 ；请在3日行程基础上，多预留一天 
 
 
 签证信息 / 货币 / 插头： 
&#8227; 从英国出发：北爱尔兰属于英国， 持英签可入境 
&#8227; 货币为英镑；插头为英标 
&#8227; 从都柏林 （爱尔兰） 出发：需要持有英签 
 
 ------- 想一起游览爱尔兰的小伙伴，顺便科普下 爱尔兰签证 ------- 
&#8227; 从贝尔法斯特去 都柏林 ：需要持有爱尔兰签证，或有BIVS标注的英签（BIVS - 英国爱尔兰签证计划） 
&#8227; 爱尔兰不属于申根国，所以无法凭 申根签证 入境爱尔兰 
&#8227; 只有国内签发的短期旅游英签，有BIVS标志；境外申请的英签一般没有；英国留学生 / 居留签证也没有 
&#8227; 请不要在无合法签证的情况下，跨越爱尔兰和北爱，一旦被发现，会留下不好的记录

 &#10103; 泰坦尼克博物馆 Titanic Belfast 返回地图 
 简介： 1912年，著名的泰坦尼克号就是在Belfast建造并起航的，2012年——泰坦尼克沉没一百年后，泰坦尼克博物馆在当年轮船建造和下水的港口建成，是世界上最大的泰坦尼克号展馆。建筑高34.7米，和泰坦尼克号的高度一样。展馆一共有9个展厅，从设计、建造、首航、沉没、打捞等各个方面进行对泰坦尼克号的介绍和纪念，展览运用了很多多媒体高科技，非常注重和参观者的互动。 
 
 门票预订： Belfast: The Titanic Experience with SS Nomadic Visit 
 门票价格： 成人&#163;24.95 （提前预订的价格，现场买贵&#163;2） ，学生&#163;21.95 （仅限于工作日）

 参观时长： 主展馆1.5小时，除此之外，门票还包含了旁边的退役游轮Nomadic号，参观需要30分钟

 &#10108; 和平墙 Peace Wall（Peace Line） 
 简介： 1969年，北爱冲突刚开始不久，英国政府为了降低天主教民族派和新教联合派两派之间冲突过程中的人员及财产损失，在两派居民社区间竖起了高墙，被称作为Peace Wall。贝尔法斯特的和平墙不同于柏林墙，并不是连续的，而是一段一段分布在不同的地方。西贝尔法斯特是两派对战最激烈的区域，所以和平墙大多位于这一区域，其中最有名的要数Cupar Way一段，其南边的Falls Road是天主教民族派的地盘，北边的Shankill Road是新教联合派的地盘，这两条路都是曾经的主战场。Cupar Way这一段的和平墙位于两条路中间，墙高7米，最底下是混凝土墙，再网上是瓦楞铁板，最上面还要加上铁丝网，整面墙大概长1km，两头均有安全门，到如今，也只是在白天开放，晚上关闭实行宵禁。现在的和平墙上已经布满了各种非常艺术的壁画和涂鸦，大多数是反战和平主题，并且不局限于北爱问题的描述。 
 如何参观： 推荐参加讲解团 Belfast: Political Conflict 3-Hour Walking Tour

 巨人之路 Giant's Causeway 
 简介： 巨人之路是北爱尔兰最著名的景点，六边形石柱造就了极具特色的海岸，这种地貌名为柱状节理。柱状节理被认为是由后山喷发后熔岩冷却凝固形成的，灼热的熔岩冷却收缩结晶时爆裂呈现出规则的六边形形态。巨人之路于1986年被列为世界自然遗产。 
 门票： 成人￡15-￡17，凭门票可免费停车 （停车场有卫生间 / 餐厅） 
 开放时间： 参考官网 
 游览时长： 自驾前往的小伙伴，至少预留1.5小时 
 非自驾： 建议报名一日游 - 黑暗树篱 / 巨人之路 / 卡里克索桥一日游（贝尔法斯特出发）

 黑暗树篱 The Dark Hedges 
 简介： 黑暗树篱被评为世界上10大最美树隧道之一，是《权利的游戏》取景地。黑暗树篱的树是山毛榉树，由Stuart家族在18世纪栽种，一共有150棵 （非常遗憾，2016年1月刮大风刮到了10棵，现在应该剩140棵） ，距离现在已经快三百年了。 
 门票： 免费，不需要门票 
 游览时长： 半小时 
 
&#8227; 黑暗树篱总长度大约600米，全程走下来要10分钟

 卡里克空中索桥 Carrick-a-Rede 
 简介： 卡里克空中索桥修建于1755年，最开始的用途是方便渔民去对面的小岛上捕三文鱼。索桥距离海面大概30米高，宽度大概是两人并肩那么宽，索桥对面的小岛上风景很棒，可以看到碧蓝色的海湾。 
 门票： 成人￡15起，凭门票可免费停车 
 开放时间： 参考官网 （开放时间受季节和天气影响较大，建议行前查询） 
 非自驾： 建议报名一日游 - 黑暗树篱 / 巨人之路 / 卡里克索桥一日游（贝尔法斯特出发） 
 
&#8227; 需要注意的是：2022年起，索桥不再接收团队游客，也就是不能再上桥走动 
&#8227; 但包含此景点的一日游产品，可以在观景台拍照（不收取门票） 
&#8227; 游览时长：跟团游10分钟拍照打卡；自驾游（买票上桥）建议至少预留1.5小时 
&#8227; 景区停车场：有卫生间

 简介： 《权力的游戏》大结局之后，拍摄片场被改建成了供粉丝参观的博物馆，陈列了剧中的场景、道具、戏服等，于2022年2月正式开放，剧粉儿小伙伴千万不要错过。

 门票预订： Game of Thrones Studio Tour Admission Ticket （可以选择含接送-贝尔法斯特 / 都柏林大巴接送）

 如何前往： 片场位于贝尔法斯特西南24英里处的Banbridge小镇，旁边还有一个奥特莱斯The Boulevard

&#8227; 自驾：导航至The Boulevard商场停车场，免费停车，然后乘坐片场shuttle bus （凭门票可免费乘坐）

 附录：如何乘轮渡前往贝尔法斯特 
&#8227; 贝尔法斯特的轮渡码头位置如下，距离市中心有一定距离 
&#8227; 公交：96路，单程&#163;2.3，大约20分钟至市中心 
&#8227; 打车：&#163;15左右，大约10分钟至市中心 
 
 
 
 
 
&#8227; 连接贝尔法斯特的轮渡路线，主要有两条： 
 
 
 
 
 
 
 
 
 利物浦至贝尔法斯特轮渡信息 
&#8227; 利物浦码头：搜索 Stena Line - Liverpool 
&#8227; 船程8小时，绝大部分情况下，每天两班，分别是10.30am、10.30pm从利物浦出发 
&#8227; 优点：可以购买晚上的船票，预订Cabin房间睡觉，睡一晚就到贝尔法斯特了 
&#8227; 船票和Cabin是分开算钱的，船票单程价格大约￡35-￡60每人 
&#8227; 每间房间的价格大约在￡35 - ￡100不等 （取决于节假日、白天夜晚班次等因素） 
&#8227; 时间充裕的小伙伴，也可以定白天的船票，船舱设施很好，不定Cabin也可以 
&#8227; 轮渡还可以载车，价格大概在￡100+一车 
&#8227; 建议从 StenaLine轮渡官网 直接买票，可以直接选择是否预订Cabin房间 
 
 
 
 
 
Cabin大概有下面几种： 
&#8227; HYGGE LOUNGE 休息室，￡20起每人 
&#8227; 4-BERTH INSIDE CABIN 四人间无窗：最便宜时仅需￡35一间房，可以住4人 
&#8227; 4-BERTH OUTSIDE CABIN 四人间有窗：最便宜时仅需￡40一间房，可以住4人 
&#8227; 2-BERTH SUPERIOR CABIN OUTSIDE 豪华两人间有窗：最便宜时仅需￡55一间房，可以住2人 
 
 
 
 
 
 
 
 
 爱丁堡 / 格拉斯哥至贝尔法斯特轮渡信息 
&#8227; 苏格兰的码头位于Cairnryan，从爱丁堡、格拉斯哥出发，需要先乘坐火车至Ayr小镇，再换乘大巴 
&#8227; Cairnryan至贝尔法斯特的船程只需要2小时15分钟 
&#8227; 单独船票价格大约￡35-￡45每人，由 StenaLine公司 运营 
&#8227; 建议 从Trainline买票 更便宜，还可以 使用Railcard 
&#8227; 直接选择Edinburg / Glasgow至Belfast Port，可以买到火车+大巴+轮渡的联程票，联程票￡35起 
&#8227; 从爱丁堡 / 格拉斯哥出发，往往全程加上等车时间，需要6-8小时，仅适合时间充裕、不怕折腾的小伙伴
